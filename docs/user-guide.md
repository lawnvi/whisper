## 连接设备

两台设备连到同一个网络并打开 Whisper 后，通常会出现在彼此的设备列表里。点击对方，由接收端确认连接；首次配对时双方需要核对并确认同一组配对码。从这台设备发起、只靠配对码的配对，要求对方也是最新版 Whisper，否则会提示更新对方；对方暂时不能更新时，可以扫描它的二维码配对。已经配对过的设备照常连接。拒绝某台设备的配对请求后，一分钟内它不能再发起新的配对请求。

列表里没有对方时，可以用二维码或地址连接：

- **手机**：点加号，在「二维码」「扫一扫」「IP / 端口」三个标签之间切换，展示本机二维码、扫描对方二维码或填写地址。
- **电脑**：点左下角这台设备的名字，面板里有本机二维码和地址；点「输入地址…」填写对方的 IP 和端口。

二维码里同时带有局域网地址和设备身份，不需要另外输入密码。默认服务端口是 `10002`，可在设置的「服务端口」里修改。

Linux 的自动发现依赖 Avahi。网络禁用了 mDNS / Bonjour 时，用 IP 连接更可靠。

连上以后，设备卡片里的「网络」一行写着到这台的网络质量和延迟，点开能看到波动和丢失。延迟高、波动大或丢包时，键鼠会卡、传文件会慢，换到 5 GHz 的 Wi-Fi、靠近路由器或插网线会好很多。下面一行是对方的地址，点一下就复制；把指针停在左下角的本机名字上可以看到本机地址。对方也是 0.0.61 及以后的版本时，卡片上还有它的版本号。

设备多了分不清时，在设备卡片的「备注名」里给它起个名字，比如「书房台式机」。侧栏、会话、托盘和各处选设备的地方都按这个名字显示。备注名只存在这台设备上，对方和别的设备看到的还是它自己的名字；清空就恢复原名。

设备列表里每台设备的圆形图标画出它是笔记本、台式机、手机还是平板，屏幕上的标志是它的系统。电脑会告诉对方自己是笔记本还是台式机（0.0.61 起），图标按这个画。

### 唤醒睡眠中的电脑

这项功能是实验性的：还没有在插着网线的真机上完整验证过，叫不醒时请[反馈](troubleshooting.md#提交问题)。

连接过一次后，Whisper 会记下对方电脑的网卡。它睡眠断开以后，在它的设备卡片上点「唤醒」就行；开始键鼠共享时，布局里睡着的电脑也会被自动唤醒，醒来后自动连上。

被唤醒的电脑要满足这些条件：

- 两台设备都是新版本，旧版本不会告诉别人自己的网卡。
- 要插网线。电脑在 Wi-Fi 下睡眠后一般收不到唤醒信号。
- 只能从睡眠中唤醒，关机或休眠不行；和发出唤醒的设备要在同一个网段。
- 系统里要打开网络唤醒：
  - **Windows**：在设备管理器里打开网卡的属性，在「电源管理」里勾选「允许此设备唤醒计算机」和「只允许幻数据包唤醒计算机」。部分电脑还要在 BIOS 里打开 Wake on LAN。
  - **macOS**：在系统设置的「能源」里（笔记本在「电池 → 选项」里）打开「唤醒以供网络访问」。
  - **Linux**：运行 `sudo ethtool -s <网卡名> wol g`，或在 NetworkManager 里把连接的 `802-3-ethernet.wake-on-lan` 设为 `magic`，这样重启后也有效。

Windows 醒来后停在锁屏界面，装了[锁屏与 UAC](#windows-锁屏与-uac) 的系统服务就能直接用键鼠输入密码。

## 发送文本和文件

打开已连接设备的会话，输入文本发送，或点输入框的 `+` 选择文件。图片可以全屏查看，音频可以直接播放，视频和其他文件交给系统应用打开。桌面端收到的文件可以在文件管理器中定位，也可以从消息里拖出来。一次发来的几张图片和视频会叠成一摞，点旁边的「展开」逐张看，再点「收起」叠回去。

不想先打开会话时：

- **Android**：在系统分享菜单里选择 Whisper。
- **桌面**：用文件右键菜单，或按 `Cmd+Option+V`（macOS）、`Ctrl+Alt+V`（Windows / Linux）发送当前剪贴板内容。

文件断线后会从已确认的位置继续传。正在共享声音或键鼠时，传文件会给它们让路。开着键鼠共享、两台设备都是这个版本时，键鼠的数据一开始排队就放慢，网络空着时再加快，开头也不会先全速跑。其他情况（只共享声音，或对方是旧版本）留出大约一成的带宽，开头几秒先全速跑一下量出网络的速度；几分钟内再传给同一台设备，不用再量。

桌面端还可以发送整个文件夹：把文件夹拖进会话，或点输入框的 `+` 选「文件夹」。文件夹作为一次传输发送，不会先打包，对方收到的是同样的目录结构。链接不会被发送；个别文件没传成时，消息上会标出数量，点开可以看到是哪些。对方的 Whisper 版本过旧时会提示先升级。

## 本机

和这台设备自己的会话，附近没有设备时也能用。文字和文件只存在这台设备上，什么都不会发出去。

在连接设备时输入这台设备自己的地址进入。打开过才出现在设备列表里；删除它不影响发给别人的消息。

## 搜索、收藏与删除

点会话右上角的信息按钮，选「搜索聊天记录」；桌面端侧栏顶部的搜索也能搜到消息。搜索范围是当前会话的文本，结果里可以选择文字、展开长消息、收藏或复制全文；顶部的「收藏」用来筛选已收藏的文本。

手机长按、桌面右键消息可以「删除」或进入「多选」。删除前会弹出确认：默认同时删除收到的本地文件，勾选「保留接收的文件」则只删除记录。自己发送的源文件始终保留。

安卓上长按文件消息选「分享」，可以把文件交给微信、邮件等其他应用发出去。

## 浏览文件

在会话顶部切到「文件」（手机上在设备页里），就能像在本机的文件管理器里一样浏览对方的文件。对方需要连着本机，并使用新版 Whisper。

每次打开时，对方会弹出询问，可以选「拒绝」或「允许」，允许后这一次可以查看和拷出。想长期允许或允许修改，在设备卡片（会话右上角的信息按钮）里打开「浏览我共享的目录」「修改我共享的目录」，关掉就收回了。

- **电脑**：对方能看到「共享的目录」里打开的磁盘，系统目录和不共享的目录除外。删除的文件进废纸篓。
- **Android**：和插数据线时一样，对方能看到内部存储，插着的 SD 卡和 U 盘也各是一项。手机没有废纸篓，删除前会再确认一次。

| 想做的事 | 怎么做 |
| --- | --- |
| 拷到本机 | 桌面端把文件拖进访达或资源管理器，边传边写；也可以右键选「拷贝到…」 |
| 拷到对方 | 把本机的文件拖进窗口，或复制后在对方的文件夹里粘贴 |
| 新建、重命名、删除 | 右键文件或空白处；手机上长按 |
| 切换列表和图标 | 工具栏的「更多」菜单，或按 `Cmd+1` / `Cmd+2`（Windows / Linux 为 `Ctrl+1` / `Ctrl+2`） |

拷贝的进度显示在页面顶部。「更多」菜单里的「传输」列出所有拷贝，可以继续、重试或停止；断线后会等对方重新连上再接着传。短时间内把同样的文件粘贴到同一个地方，只算一次。

### 电脑共享哪些目录

在电脑的设置里打开「共享与权限 → 共享的目录」，分两组：

- **磁盘和分区**：每块盘一个开关。系统盘（Windows 的 C 盘、Mac 的 Macintosh HD、Linux 的根分区）默认打开，只共享上面的主目录，盘上别的地方放的是系统和装的程序，不共享。其他磁盘、分区和 U 盘默认关闭，打开就共享整块盘里的普通目录；挂在主目录里的分区也是单独一块，关着就不共享。
- **不共享的目录**：点「添加不共享的目录…」选一个目录，它和里面的一切都不再给对方看。点一行可以在访达（文件资源管理器、文件管理器）中显示它，或者「恢复共享」。选到的目录已经在一个不共享的目录里时会提示已经不共享；选一个包住已有几项的上层目录，那几项会合成这一条；选整块盘（或系统盘上的主目录）就等于关掉这块盘。拔掉的 U 盘上的目录会写「找不到」。

无论怎么设置，下面这些都不共享：系统和程序的目录（Windows、Program Files、ProgramData，Mac 的系统、应用程序和资源库，Linux 的 /usr、/etc 这类）、各盘最上层的隐藏项和回收站、别的用户的目录、主目录里以 `.` 开头的隐藏项（比如 `.ssh`、`.config`）、Windows 的 `AppData` 和 Whisper 自己的数据。指向这些地方的符号链接也打不开。

这些设置对所有允许浏览的设备都一样。改动从对方的下一次操作起生效，不用重新连接；新打开的盘在对方下次打开文件时出现。

- 共享的盘本身不能被重命名、移走或删除。对方在共享的盘里打开一个装着不共享目录的上层目录时，看不到那个目录，也不能把整个上层目录拷走、改名、移走或删除，可以拷、改里面其他的东西。
- Git 仓库的钩子和配置（`.git` 里的 `hooks` 和 `config`），对方只能看、不能改，也不能新建、删除或换掉 `.git`。
- 对方用的是旧版 Whisper 时也能浏览。

### 挂载对方共享的目录

在 macOS、Windows 和 Linux 上，还可以把对方共享的目录挂载进系统的文件管理器，用任何应用直接打开，不必先拷贝过来。挂载看到的和在「文件」里浏览看到的一样：电脑是它「共享的目录」，Android 是内部存储和插着的 SD 卡、U 盘。

- 点会话右上角的信息按钮，打开「挂载」，以后每次连上都会自动挂载。
- 挂载的位置：
  - **macOS**：访达侧边栏的「位置」里，每台设备一块盘，名字是「设备名 (Whisper)」。
  - **Windows**：「此电脑」的「设备和驱动器」里，名字是「设备名 (Whisper)」；资源管理器左侧的导航栏里也有，带 Whisper 图标。
  - **Linux**：主目录下的 `Whisper/设备名 (Whisper)`，GNOME「文件」的侧边栏和 KDE Dolphin 的「位置」里各单独一项。需要先安装 fuse3。
- 挂载后可以像本机文件一样打开、修改、新建、重命名和删除：
  - 保存时先写进对方文件旁边的隐藏副本，写完再一次性换上去，中途断线不会留下写了一半的文件。
  - 写的过程中对方那边也改了这个文件的话，原文件不动，你写的内容另存为「文件名 (本机名)」。
  - 删除对方原有的文件会进对方的废纸篓（Android 没有回收站，直接删除）；在挂载里新建的文件删除时直接删掉。
  - 对方在设备卡片里关掉「修改我共享的目录」后，挂载只能打开和拷出。
  - macOS 上访达自己写的 `._` 和 `.DS_Store` 文件只留在本机，不会写到对方那边。
  - Windows 上，在资源管理器里新建或改好的文件，关闭后几秒内传到对方。
- 打开哪个文件才传哪一段，速度取决于网络和对方设备。
- 对方没设「始终允许」时，每次挂载都要在对方那边点允许。
- 断开连接时自动卸载，「挂载」保持打开，重新连上后自动挂回。在访达或 Linux 的文件管理器里推出后，这个开关会自动关闭。
- 在 Windows 上，对方改动的文件约 5 秒内会更新，新文件在下次打开所在文件夹时出现。

## 共享链接

想把本机的文件给一台没装 Whisper 的设备，可以生成一个链接。同一局域网里的设备用浏览器打开就能下载，不需要配对。Android、macOS、Windows 和 Linux 支持。

1. 打开任意一台设备的「文件」，在侧边栏选「本机」。
2. 右键文件或文件夹，选「创建共享链接…」，可以先选好多个再右键；手机上长按，或多选后点底部的「共享链接」。
3. 按需填写路由和密码：
   - 路由不填就随机生成；打开「简短路由」只有 4 个字符，方便口头告诉别人。
   - 密码可以不填。
4. 创建后会显示链接和二维码，可以复制，也可以让对方用手机相机扫码。电脑连着多个网络时，可以切换链接里的地址。

对方打开链接后：

- 一个文件时显示下载页；文件夹或多个文件可以逐层浏览、逐个下载，也可以打包成 zip 一次下载。
- 大文件下载中断后可以接着下，视频和音频可以直接在浏览器里播放。
- 设了密码时，先输入密码才能看到内容。

所有链接都在侧边栏的「共享链接」里（手机上在「文件」首页）：

- 每条链接显示状态、访问次数、下载次数和最近访问时间，可以复制、看二维码、开启、关闭或删除。删除链接不影响本机的文件。
- 顶部的「文件服务」显示本机地址和端口（默认 `10003`，被占用时自动换一个）。服务只在至少有一条链接开着（或者正在用网页传输）时运行；关掉服务后链接都还在，只是暂时打不开。
- 只接受局域网内的访问。链接走普通 HTTP，同一网络里的人可能看到传输的内容，密码只防止别人随意打开。

## 网页传输

对方没装 Whisper（比如 iPhone、借来的电脑），也可以用浏览器和这台互发文字和文件。macOS、Windows、Linux 和 Android 都能当这台；对方有浏览器就行。这是新功能，目前只在 Mac 当这台、对方用电脑浏览器或安卓手机上的 Chrome 时试过。

1. 电脑上点左下角这台的名字，手机上进「连接设备」，在二维码下面点「对方没有 Whisper？用网页传输」。
2. 对方用相机扫二维码，或者在浏览器里输入下面的地址（比如 `http://192.168.1.5:10003/`）。电脑连着多个网络时，可以点地址右边的箭头换一个。
3. 对方的网页上会出现一个 4 位数，这台的灵动岛上也弹出请求。两边数字一样就点「允许」。60 秒没答复请求作废，对方可以再试。
4. 允许后对方出现在设备列表里，名字按它的浏览器猜（iPhone、Android、Windows……），可以改备注名。之后像和其他设备一样发文字、文件、截图和剪贴板里的内容。

对方的网页上：

- 左边的「+」选文件（手机上可以从相册选），电脑上也可以把文件拖进来，或者把截图粘贴进输入框。安卓手机上点「+」先选「照片和视频」或「文件」。在小米手机上选「文件」后，系统框里那一项也叫「照片和视频」，点进去切到「浏览」就能选任何文件。
- 发过来的图片和视频能直接看，其他文件点右边的箭头下载。Chrome 和 Edge 下载时会提示无法安全下载（网页是 http 的），选「保留」才会下完。iPhone 上要把图片存到照片，打开大图后按住图片。
- 网页只有中文和英文，按浏览器的语言显示，右上角（对话里是左上角的地球按钮）可以切换。
- 页面底部有 Whisper 官网和 GitHub 的链接。

结束和重连：

- 这台在对话顶部点「断开连接」、网页上点「断开」，或者网页关掉、断网超过 10 分钟，连接就结束。聊天记录和收到的文件都留着，设备列表里那一行变成离线。
- 网页刷新或者手机切到别的应用再回来，10 分钟内会自动接上，不用再确认。结束以后同一个浏览器再打开，要这台再点一次「允许」。
- 这台的 Whisper 退出后，所有网页连接都结束。
- 只有面板开着的时候才接受新的请求；已经连上的不受影响。

限制：

- **不加密。** 网页和这台之间走普通 HTTP，同一网络里的人可能看到传的内容，别在公共网络里传私密文件。
- 两个方向都不能发文件夹，可以先压缩成一个文件。
- 网页上传的文件不做整个文件的校验，靠网络本身保证不出错；传到一半断开会从断开的地方接着传。
- 网页没有剪贴板同步、通知和后台在线，传文件时网页要开着。
- 同时最多 4 个网页访客。

## 窗口流转

把一台设备上的窗口或应用打开到另一台设备上，在那边看和操作。比如在手机或平板上接着用电脑上的应用，把安卓手机的应用放到电脑上用键鼠操作，或者把电脑上的一个窗口挪到另一台电脑的屏幕上。

### 打开对方的窗口

在会话顶部切到「应用」（手机上在设备页里）。页面里列出对方的最近任务、窗口和应用，点一个就在本机打开。

- **手机和平板**：窗口铺满屏幕，用手指操作，也可以接键盘鼠标。弹出键盘时，对方的窗口会跟着变矮，不会被挡住。可以旋转成横屏。
- **电脑**：每个窗口是一个独立的系统窗口，可以调整大小、全屏，用本机的键鼠和输入法操作。
- 开着的窗口排成一叠卡片，可以在它们之间切换。
- 窗口的声音会一起送过来。
- 「画质」有流畅、标准、高清、超清四档，越高越清晰，也越占网络。
- 「暂停」只停画面、省网络。手机和平板离开窗口页时会自动暂停，暂停超过 10 分钟自动关闭。
- 关掉本机上的窗口后，它在对方那边回到原来的位置。「关闭窗口」会在对方那边真正关掉它；有没保存的内容时，对方的应用可能会先问是否保存。

### 把窗口送过去

在流转页点「送到 <设备名>」，选一个本机窗口。窗口会挪到那台设备上，不再占本机屏幕；那边关掉后自动回到原处。对方是手机或平板时会弹出「<设备名> 送来了一个窗口」，点「查看」打开；是电脑时直接打开。

### 被流转的设备

被打开的窗口在本机后台继续运行，不占屏幕：macOS 和 Linux 上挪到一块看不见的虚拟屏上，Windows 上挪到屏幕外面。结束后回到原来的位置。少数 Windows 应用不支持在后台运行，会留在原位置流转。

桌面端「设置 → 权限与共享」里的「允许查看和操作本机窗口」默认打开，关掉后其他设备看不到本机的窗口。锁屏时无法流转；以管理员身份运行的窗口和不允许录屏的窗口不能流转。

| 系统 | 要求 |
| --- | --- |
| macOS | 12.3 及以上。在「系统设置 › 隐私与安全性」里允许 Whisper 使用「屏幕与系统录音」，要让对方操作还需要「辅助功能」。「设置 → 权限与共享」里能看到这些权限的状态 |
| Windows | Windows 10（1903）及以上 |
| Linux | GNOME 45 及以上或 KDE Plasma 6 的 Wayland 会话。GNOME 第一次要在设置里安装「窗口流转组件」，装好后注销并重新登录一次；KDE Plasma 不用安装，也不弹授权窗口。X11 暂时只能接收 |
| Android | Android 10 及以上，见下文 |

Linux 上显示流转来的画面需要 FFmpeg（4 及以上）。让别的设备流转本机窗口时，FFmpeg 还要带 H.264 编码器（x264 或 openh264，Fedora 默认没有）。

### 流转安卓手机的应用

安卓手机上的应用可以流转到电脑上。手机上的 Whisper 需要和电脑配对并连着。

手机要先开启「窗口流转服务」，之后配对过的设备都能流转这台手机，不需要电脑，也不需要 adb。

Android 12 及以上可以在手机上自己开启，手机要连着 Wi-Fi：

1. 在手机 Whisper 里打开「设置 → 窗口流转服务」。
2. 点「打开无线调试」，在系统的开发者选项里打开「无线调试」，再点「使用配对码配对设备」。如果还没有开发者选项，页面上会先让你打开它。
3. 不要离开配对码页面，否则配对码会失效。下拉通知栏，在「输入配对码」这条通知上点「填写」（看不到按钮就先展开它），填入系统显示的 6 位数字。也可以分屏后填在 Whisper 的页面上。

配对只需要一次。手机重启后服务会停止，到同一页点「开启服务」就行。打开「打开 Whisper 时自动开启」后，Whisper 启动或有设备来查看时会自己打开无线调试、开启服务，再把无线调试关上。这需要授予 Whisper 一项系统权限，换到新的 Wi-Fi 时系统可能会询问是否允许。

Android 10、11 不能自己开启，要用一台装有 adb 的电脑（Android SDK Platform-Tools；Whisper 会在 Android SDK 的默认位置和 PATH 里找，安装包里不带）。在手机的开发者选项里打开「USB 调试」，用数据线连上这台电脑，并在手机上允许它调试。之后在这台电脑的流转页里就能看到手机的应用。手机重启后要再开启一次。

服务状态在手机 Whisper 的「设置 → 窗口流转服务」里，可以随时停止。卸载 Whisper 时服务会自己结束并删掉文件；系统「无线调试」里的配对记录要手动删除。

流转的应用运行在手机的一块虚拟屏上，手机本身可以继续做别的。几点说明：

- 在手机上点开正在流转的应用，它会回到手机屏幕；电脑上点一下就能拿回来。
- 应用的声音会一起送到电脑上（需要 Android 13 及以上）。
- 不允许录屏的应用（比如部分银行 App）显示不出来。
- 部分手机锁屏后画面会停。
- 小米手机还要在开发者选项里打开「USB 调试（安全设置）」，然后重启手机。

## 剪贴板同步

「同步剪贴板」默认关闭，在设置里开启。

- 普通会话只同步到当前已连接且可信的设备。
- 键鼠共享时会同步到参与共享的已连接设备，以最后一次复制为准。
- 同步的内容不会进入聊天记录。
- 图片和文件剪贴板只在桌面端键鼠共享时同步。文件在粘贴时才开始传：两台都是新版时，单个文件最大 64 GB、一次最多 20 个，没有马上到的，在 macOS 和 Windows 上屏幕顶部会显示进度，可以取消，键鼠照常用；在文件夹或桌面里粘贴的，传完直接放进粘贴时的那个文件夹；在别的应用里粘贴的，传完自动粘贴，那时前台换了窗口就提示再按一次粘贴键；前一次还没传完又粘贴了别的文件，两次都会传完、都会粘贴；和旧版之间是单个 64 MB、一次 128 MB。

Android 只同步文本。受 [Android 10 的隐私限制](https://developer.android.com/about/versions/10/privacy/changes#clipboard-data)，Whisper 不在前台时读不到其他 App 里新复制的内容；回到 Whisper 后会检查剪贴板并补发。

## 键鼠共享

点桌面端侧栏顶部的键盘图标，把对方的屏幕拖到本机屏幕旁边，然后打开右上角的开关。之后指针从对应的屏幕边缘移出去就到了对方设备上，键盘输入跟随指针所在的设备。

需要跨设备粘贴时，先开启剪贴板同步。

两台电脑都是 0.0.60 或更新的版本时，指针移动走一条单独的加密 UDP 通道，Wi-Fi 偶尔丢包也不会让指针停住再跳；按键和点击照样一个不丢、顺序不乱。对方是旧版本，或者防火墙挡住了 UDP，就自动用原来的连接，功能不受影响。

### 退出与停止

- 主控端和被控端都可以主动停止共享。
- 指针在其他设备上时点不到本机的停止按钮，这时在主控端按 `Ctrl+Alt+Esc`（macOS 为 `Control+Option+Esc`），键鼠立即回到本机。键鼠页没有选中屏幕时，底部会显示这个快捷键。
- 对方断开连接后，指针会自动回到主控端。
- 一台设备同一时间只能处于一种角色：正在被控制的设备不能再发起共享，切换前先停止当前共享。

### 权限与平台限制

- **macOS**：按提示授予辅助功能权限。
- **Linux**：X11 会话都可以用。Wayland 下支持 GNOME，不用额外授权，控制期间顶栏会显示远程控制的图标。GNOME 46 以前的版本（如 Ubuntu 22.04）只能被控制，要用它控制别的电脑，请在登录界面选「Ubuntu on Xorg」。从手机输入中文等当前键盘布局打不出的字，需要装上设置里的「窗口流转组件」（GNOME 45 及以上）。KDE Plasma 第一次被控制时会弹出系统的授权窗口，勾选记住后不再弹，中文等文字可以直接输入；用它控制别的电脑时，每次开始都要授权一次（KDE 目前的限制）。其他 Wayland 桌面还没有验证过，不保证可用。
- **Windows**：如果指针一顿一顿地移动，或文件传输时快时慢，检查「设置 → 系统 → 投影到此电脑」。它开启时无线网卡可能要同时维持一个 Wi-Fi Direct 网络，使 Wi-Fi 连接出现周期性延迟；不用无线投屏时设为「始终关闭」。

### Windows 锁屏与 UAC

Windows 锁屏后，普通程序无法向锁屏界面输入。Whisper 的安装包会附带安装一个系统服务（第一次安装时需要管理员确认一次），让互信设备可以在锁屏界面输入密码。

- 服务状态显示在「设置 → 系统行为 → 锁屏与 UAC 时接收键鼠」，点这一行可以卸载或修复。在这里卸载后，以后升级不会再自动装回。
- 在 Whisper 里更新时不出现安装向导：新版本装回原来的位置，装完自动重新打开。更新不需要管理员确认：服务在 Whisper 重新打开后自己更新，只接受签名有效、版本更新的文件。从 0.0.61 及更早的版本升级时，服务还不会自己更新，这一次仍要管理员确认。从没装上过服务的，更新时不会再问。
- 服务默认只在锁屏时生效，解锁后弹出的 UAC 提示不能操作。需要时打开同一行末尾的开关（默认关闭，开和关都需要管理员确认）。
- 开关打开后，本机上以你的身份运行的任何程序都可以借 Whisper 绕过 UAC 的确认，请在了解这个风险后再开启。卸载服务会同时关闭它。
- 重启后还没登录时 Whisper 没有运行，无法控制。

## 用 Android 手机控制电脑

手机和电脑需要已经连接并互相信任，电脑已登录且正在运行 Whisper。在 Android 上打开这台电脑的设备页（会话右上角），点「控制电脑」，再点顶部的开始按钮。

| 操作 | 方式 |
| --- | --- |
| 体感移动 | 点中央区域开启，握住手机转动手腕移动指针，再点一次暂停 |
| 触控板 | 单指移动、轻点左击，双指轻点右击、双指滑动滚动 |
| 点击与拖拽 | 底部左右键分别点击；按住左键再移动即可拖拽 |
| 滚动 | 左右键中间是滚动区：体感模式下按住并上下转腕，触控板模式下上下滑动 |
| 虚拟键盘 | 顶部的切换按钮打开键盘，可切换数字、符号和功能键；先点修饰键再点普通键可发送组合键 |
| 输入文字 | 键盘页的输入框使用手机输入法，适合中文、表情和多行内容 |

- 顶部设置里可以调指针速度、滚动速度、体感灵敏度并校准。
- 连接了多台电脑时，点顶部的电脑名称切换目标，一次只控制一台。
- 返回、切到后台、锁屏或断开连接都会停止控制，重连后需要手动再开始。
- 体感模式需要陀螺仪和重力传感器，没有时自动使用触控板。
- 这个功能不传回电脑画面，也不能唤醒电脑或在锁屏界面登录。

## 系统音频共享

点桌面端侧栏顶部的喇叭，勾选一台或多台已连接的设备，再点设备图上的播放按钮。多设备播放支持基础同步，勾选两台以上时可以分配左右声道。

别的设备把声音放到这台时，这一页会换成来源设备，可以调增益、暂停和断开。在那台设备上暂停或断开后，来源这边会取消它的勾选并写「对方已停止播放」；那边点继续会自动勾回，也可以在来源这边重新勾选。勾选表示声音正在放过去：停止后列表里不再打勾，刚才放过的写「已停止」，点播放按钮再放给它们。

电脑之间的声音和键鼠一样走 UDP（两边都要 0.0.60 或更新的版本），偶尔丢的一小段会自动补上，不会断一下。放到 Android 手机上的声音仍用原来的连接。

## 截图

点桌面端输入框里的截图按钮，或按设置里配置的截图快捷键。点击选中窗口，或拖动框选区域，松手后工具栏就在选区旁边：可以框、圈、加箭头、画笔、文字和马赛克，按住 Shift 画正方形、正圆和八个方向的箭头。双击选区或按 Enter 复制到剪贴板，也可以存成文件；按 `Esc` 或右键取消。截图不会自动发送，在 Whisper 输入框里粘贴后可以预览并发送，点预览小图可以继续标注。

选区跨两块屏幕时不能标注，只能复制或取消。Wayland 由系统选区，选完进剪贴板，粘贴到输入框后点小图标注。

Linux 上的可用程度取决于桌面环境提供的截图服务。

## Android 通知

在 Android 上授予通知监听权限后，选择要转发的 App。适合验证码这类短消息。

## 电视投屏

在桌面端设置里开启「电视投屏」后，同一局域网里的视频 App 可以把视频投到这台电脑上，不需要 Whisper 配对。功能为实验性，默认关闭，详见 [电视投屏说明](internals/cast-receiver.md)。

## 诊断信息

Whisper 没有正常运行时（数据库打不开、启动失败、连接服务或发现设备没起来），灵动岛会一直提示，修好才消失。点提示上的「查看」，或在设置里打开「诊断信息」，可以看到各项状态，并拷贝或反馈。

诊断信息不含消息、文件和设备名，只有系统版本、本机网络地址和运行记录。只有你发出去，它才会离开这台设备。
