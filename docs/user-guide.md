## 连接设备

两台设备连到同一个网络并打开 Whisper 后，通常会出现在彼此的设备列表里。点击对方，由接收端确认连接；首次配对时双方需要核对并确认同一组配对码。

列表里没有对方时，点设备列表顶部的二维码图标打开「连接设备」：

- **手机**：在「二维码」「扫一扫」「IP / 端口」三个标签之间切换，展示本机二维码、扫描对方二维码或填写地址。
- **电脑**：左侧展示本机二维码，右侧切换「本机信息」和「IP / 端口」。

二维码里同时带有局域网地址和设备身份，不需要另外输入密码。默认服务端口是 `10002`，可在设置的「服务端口」里修改。

Linux 的自动发现依赖 Avahi。网络禁用了 mDNS / Bonjour 时，用 IP 连接更可靠。

## 发送文本和文件

打开已连接设备的会话，输入文本发送，或点附件按钮选择文件。图片可以全屏查看，音频可以直接播放，视频和其他文件交给系统应用打开。桌面端收到的文件可以在文件管理器中定位，也可以从消息里拖出来。

不想先打开会话时：

- **Android**：在系统分享菜单里选择 Whisper。
- **桌面**：用文件右键菜单，或按 `Cmd+Option+V`（macOS）、`Ctrl+Alt+V`（Windows / Linux）发送当前剪贴板内容。

文件断线后会从已确认的位置继续传。

桌面端还可以发送整个文件夹：把文件夹拖进会话，或点附件按钮选「文件夹」。文件夹作为一次传输发送，不会先打包，对方收到的是同样的目录结构。链接不会被发送；个别文件没传成时，消息上会标出数量，点开可以看到是哪些。对方的 Whisper 版本过旧时会提示先升级。

## 搜索、收藏与删除

在会话设置里打开「搜索聊天记录」，宽窗口的桌面端也有直接的搜索入口。搜索范围是当前会话的文本，结果里可以选择文字、展开长消息、收藏或复制全文；顶部的「收藏」用来筛选已收藏的文本。

手机长按、桌面右键消息可以「删除」或进入「多选」。删除前会弹出确认：默认同时删除收到的本地文件，勾选「保留接收的文件」则只删除记录。自己发送的源文件始终保留。

## 浏览文件

点会话右上角的 ⋯ 打开「设备详情」，再点「文件」，就能像在本机的文件管理器里一样浏览对方的文件。对方需要连着本机，并使用新版 Whisper。

每次打开时，对方会弹出「想浏览你的文件」，可以选「拒绝」「允许这一次」或「始终允许」。在设备详情里关掉「始终允许浏览我的文件」，就收回了对那台设备的始终允许。

- **电脑**：对方能看到主目录（Windows 上还有各个磁盘），删除的文件进废纸篓。
- **Android**：对方能看到内部存储。手机没有废纸篓，删除前会再确认一次。

| 想做的事 | 怎么做 |
| --- | --- |
| 拷到本机 | 桌面端把文件拖进访达或资源管理器，边传边写；也可以右键选「拷贝到…」 |
| 拷到对方 | 把本机的文件拖进窗口，或复制后在对方的文件夹里粘贴 |
| 新建、重命名、删除 | 右键文件或空白处；手机上长按 |
| 切换列表和图标 | 工具栏的切换按钮，或按 `Cmd+1` / `Cmd+2`（Windows / Linux 为 `Ctrl+1` / `Ctrl+2`） |

拷贝的进度显示在窗口顶部。侧边栏的「传输」里列出所有拷贝，可以继续、重试或停止；断线后会等对方重新连上再接着传。短时间内把同样的文件粘贴到同一个地方，只算一次。

### 挂载到本机

在 macOS、Windows 和 Linux 上，还可以把对方的文件挂进系统的文件管理器，用任何应用直接打开，不必先拷贝过来。Android、电脑都可以被挂载。

- 在设备详情里打开「挂载到本机」，以后每次连上都会自动挂载。只想用一次的话，在「文件」窗口的侧边栏右键这台设备，选「在访达中打开」（Windows 上是「在文件资源管理器中打开」）。
- 挂载的位置：
  - **macOS**：访达侧边栏的「位置」里，名字是对方的设备名。
  - **Windows**：资源管理器左侧的导航栏，带 Whisper 图标。
  - **Linux**：主目录下的 `Whisper/<设备名>`，GNOME「文件」的侧边栏里也能看到。需要先安装 fuse3。
- 挂载是只读的：可以打开和拷出，不能在里面修改、新建或删除。要改对方的文件，用「文件」窗口。
- 打开哪个文件才传哪一段，速度取决于网络和对方设备。
- 对方没设「始终允许」时，每次挂载都要在对方那边点允许。
- 断开连接时自动卸载，「挂载到本机」保持打开，重新连上后自动挂回。在访达或 Linux 的文件管理器里推出后，这个开关会自动关闭。
- 在 Windows 上，对方改动的文件约 5 秒内会更新，新文件在下次打开所在文件夹时出现。

## 共享链接

想把本机的文件给一台没装 Whisper 的设备，可以生成一个链接。同一局域网里的设备用浏览器打开就能下载，不需要配对。Android、macOS、Windows 和 Linux 支持。

1. 打开任意一台设备的「文件」，在侧边栏选「本机」。
2. 右键文件或文件夹，选「创建共享链接…」，可以先选好多个再右键；手机上长按，或多选后点底部的「共享链接」。
3. 按需填写路由和密码：
   - 路由不填就随机生成；打开「简短路由」只有 4 个字符，方便口头告诉别人。
   - 密码可以不填。
4. 创建后会显示链接和二维码，可以复制，也可以让对方用手机相机扫码。电脑连着多个网络时，可以切换链接里的地址。

对方打开链接后：

- 一个文件时显示下载页；文件夹或多个文件可以逐层浏览、逐个下载，也可以打包成 zip 一次下载。
- 大文件下载中断后可以接着下，视频和音频可以直接在浏览器里播放。
- 设了密码时，先输入密码才能看到内容。

所有链接都在侧边栏的「共享链接」里（手机上在「文件」首页）：

- 每条链接显示状态、访问次数、下载次数和最近访问时间，可以复制、看二维码、开启、关闭或删除。删除链接不影响本机的文件。
- 顶部的「文件服务」显示本机地址和端口（默认 `10003`，被占用时自动换一个）。服务只在至少有一条链接开着时运行；关掉服务后链接都还在，只是暂时打不开。
- 只接受局域网内的访问。链接走普通 HTTP，同一网络里的人可能看到传输的内容，密码只防止别人随意打开。

## 窗口流转

把一台设备上的窗口或应用打开到另一台设备上，在那边看和操作。比如在手机或平板上接着用电脑上的应用，把安卓手机的应用放到电脑上用键鼠操作，或者把电脑上的一个窗口挪到另一台电脑的屏幕上。

### 打开对方的窗口

在设备详情里点「流转」。页面里列出对方的最近任务、窗口和应用，点一个就在本机打开。

- **手机和平板**：窗口铺满屏幕，用手指操作，也可以接键盘鼠标。弹出键盘时，对方的窗口会跟着变矮，不会被挡住。可以旋转成横屏。
- **电脑**：每个窗口是一个独立的系统窗口，可以调整大小、全屏，用本机的键鼠和输入法操作。
- 开着的窗口排成一叠卡片，可以在它们之间切换。
- 窗口的声音会一起送过来。
- 「画质」有流畅、标准、高清、超清四档，越高越清晰，也越占网络。
- 「暂停」只停画面、省网络。手机和平板离开窗口页时会自动暂停，暂停超过 10 分钟自动关闭。
- 关掉本机上的窗口后，它在对方那边回到原来的位置。「关闭窗口」会在对方那边真正关掉它；有没保存的内容时，对方的应用可能会先问是否保存。

### 把窗口送过去

在流转页点「送到 <设备名>」，选一个本机窗口。窗口会挪到那台设备上，不再占本机屏幕；那边关掉后自动回到原处。对方是手机或平板时会弹出「<设备名> 送来了一个窗口」，点「查看」打开；是电脑时直接打开。

### 被流转的设备

被打开的窗口在本机后台继续运行，不占屏幕：macOS 和 Linux 上挪到一块看不见的虚拟屏上，Windows 上挪到屏幕外面。结束后回到原来的位置。少数 Windows 应用不支持在后台运行，会留在原位置流转。

桌面端「设置 → 权限与共享」里的「允许查看和操作本机窗口」默认打开，关掉后其他设备看不到本机的窗口。锁屏时无法流转；以管理员身份运行的窗口和不允许录屏的窗口不能流转。

| 系统 | 要求 |
| --- | --- |
| macOS | 12.3 及以上。在「系统设置 › 隐私与安全性」里允许 Whisper 使用「屏幕与系统录音」，要让对方操作还需要「辅助功能」。「设置 → 权限与共享」里能看到这些权限的状态 |
| Windows | Windows 10（1903）及以上 |
| Linux | GNOME 的 Wayland 会话。第一次要在设置里安装「窗口流转组件」，装好后注销并重新登录一次。KDE 和 X11 暂时只能接收 |
| Android | Android 10 及以上，见下文 |

Linux 上显示流转来的画面需要 FFmpeg 的 libavcodec。

### 流转安卓手机的应用

安卓手机上的应用可以流转到电脑上。手机上的 Whisper 需要和电脑配对并连着。

第一次要用一台电脑开启。这台电脑上要装有 adb（Android SDK Platform-Tools；Whisper 会在 Android SDK 的默认位置和 PATH 里找，安装包里不带）。在手机的开发者选项里打开「USB 调试」，用数据线连上这台电脑，并在手机上允许它调试（也可以改用「无线调试」）。之后在这台电脑的流转页里就能看到手机的应用。

开启后，手机上的窗口流转服务会一直运行，你信任的其他电脑不插线也能流转这台手机；手机重启后要再用电脑开启一次。服务状态在手机 Whisper 的「设置 → 窗口流转服务」里，可以随时停止。

流转的应用运行在手机的一块虚拟屏上，手机本身可以继续做别的。几点说明：

- 在手机上点开正在流转的应用，它会回到手机屏幕；电脑上点一下就能拿回来。
- 应用的声音会一起送到电脑上（需要 Android 13 及以上）。
- 不允许录屏的应用（比如部分银行 App）显示不出来。
- 部分手机锁屏后画面会停。
- 小米手机还要在开发者选项里打开「USB 调试（安全设置）」，然后重启手机。

## 剪贴板同步

「自动同步剪贴板」默认关闭，在设置里开启。

- 普通会话只同步到当前已连接且可信的设备。
- 键鼠工作区会同步到工作区内已连接的设备，以最后一次复制为准。
- 同步的内容不会进入聊天记录。
- 图片和文件剪贴板只在桌面端的键鼠工作区里同步，并有单文件和批次大小限制。

Android 只同步文本。受 [Android 10 的隐私限制](https://developer.android.com/about/versions/10/privacy/changes#clipboard-data)，Whisper 不在前台时读不到其他 App 里新复制的内容；回到 Whisper 后会检查剪贴板并补发。

## 键鼠共享

在桌面端打开键鼠工作区，把对方的屏幕拖到本机屏幕旁边，然后点「启动」。之后指针从对应的屏幕边缘移出去就到了对方设备上，键盘输入跟随指针所在的设备。

需要跨设备粘贴时，先开启剪贴板同步。

### 退出与停止

- 主控端和被控端都可以主动停止共享。
- 指针在其他设备上时点不到本机的停止按钮，这时在主控端按 `Ctrl+Alt+Esc`（macOS 为 `Control+Option+Esc`），键鼠立即回到本机。工作区的屏幕排列区域底部会一直显示这个快捷键。
- 对方断开连接后，指针会自动回到主控端。
- 一台设备同一时间只能处于一种角色：正在被控制的设备不能再发起共享，切换前先停止当前共享。

### 权限与平台限制

- **macOS**：按提示授予辅助功能权限。
- **Linux**：需要 X11，Wayland 下不可用。
- **Windows**：如果指针一顿一顿地移动，或文件传输时快时慢，检查「设置 → 系统 → 投影到此电脑」。它开启时无线网卡可能要同时维持一个 Wi-Fi Direct 网络，使 Wi-Fi 连接出现周期性延迟；不用无线投屏时设为「始终关闭」。

### Windows 锁屏与 UAC

Windows 锁屏后，普通程序无法向锁屏界面输入。Whisper 的安装包会附带安装一个系统服务（安装和升级时各需要管理员确认一次），让互信设备可以在锁屏界面输入密码。

- 服务状态显示在「设置 → 系统行为 → 锁屏与 UAC 时接收键鼠」，点这一行可以卸载或修复。在这里卸载后，以后升级不会再自动装回。
- 服务默认只在锁屏时生效，解锁后弹出的 UAC 提示不能操作。需要时打开同一行末尾的开关（默认关闭，开和关都需要管理员确认）。
- 开关打开后，本机上以你的身份运行的任何程序都可以借 Whisper 绕过 UAC 的确认，请在了解这个风险后再开启。卸载服务会同时关闭它。
- 重启后还没登录时 Whisper 没有运行，无法控制。

## 用 Android 手机控制电脑

手机和电脑需要已经连接并互相信任，电脑已登录且正在运行 Whisper。在 Android 上进入这台电脑的会话，点「控制电脑」图标，再点顶部的开始按钮。

| 操作 | 方式 |
| --- | --- |
| 体感移动 | 点中央区域开启，握住手机转动手腕移动指针，再点一次暂停 |
| 触控板 | 单指移动、轻点左击，双指轻点右击、双指滑动滚动 |
| 点击与拖拽 | 底部左右键分别点击；按住左键再移动即可拖拽 |
| 滚动 | 左右键中间是滚动区：体感模式下按住并上下转腕，触控板模式下上下滑动 |
| 虚拟键盘 | 顶部的切换按钮打开键盘，可切换数字、符号和功能键；先点修饰键再点普通键可发送组合键 |
| 输入文字 | 键盘页的输入框使用手机输入法，适合中文、表情和多行内容 |

- 顶部设置里可以调指针速度、滚动速度、体感灵敏度并校准。
- 连接了多台电脑时，点顶部的电脑名称切换目标，一次只控制一台。
- 返回、切到后台、锁屏或断开连接都会停止控制，重连后需要手动再开始。
- 体感模式需要陀螺仪和重力传感器，没有时自动使用触控板。
- 这个功能不传回电脑画面，也不能唤醒电脑或在锁屏界面登录。

## 系统音频共享

在桌面端的设备工具区选择音频共享，再选择一台或多台已连接、支持播放的设备。多设备播放支持基础同步和左右声道分配。

## 截图

点桌面端的截图按钮，或按设置里配置的截图快捷键。点击选中窗口，或拖动框选区域，确认后图片进入剪贴板；按 `Esc` 取消。截图不会自动发送，在 Whisper 输入框里粘贴后可以预览并发送。

Linux 上的可用程度取决于桌面环境提供的截图服务。

## Android 通知

在 Android 上授予通知监听权限后，选择要转发的 App。适合验证码这类短消息。

## 电视投屏

在桌面端设置里开启「电视投屏」后，同一局域网里的视频 App 可以把视频投到这台电脑上，不需要 Whisper 配对。功能为实验性，默认关闭，详见 [电视投屏说明](cast_receiver.md)。
