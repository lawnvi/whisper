# Whisper 排障指南

[English](troubleshooting_en.md) · [使用指南](user-guide.md) · [返回 README](../README.md)

先看这两处，多数问题能直接找到原因：

- **连接诊断**：桌面端点会话右上角的信息按钮，手机进入这台设备的页面，点「连接诊断」。它会依次检查本机网络、对方的地址、对方的 Whisper 和加密连接，告诉你卡在哪一步。
- **诊断信息**：在设置里打开「诊断信息」，可以看到数据库、本机服务、设备发现等各项状态。Whisper 没有正常运行时，灵动岛也会一直提示。

## 装不上、打不开

**Windows 提示「Windows 已保护你的电脑」**：安装包没有代码签名。点「更多信息」，再点「仍要运行」。

**杀毒软件报毒或拦截**：Whisper 要监听局域网端口、读写剪贴板、模拟键盘鼠标，安装包又没有签名，部分杀毒软件会误报。请只从 [GitHub Releases](https://github.com/lawnvi/whisper/releases) 下载，再在杀毒软件里把 Whisper 加入信任。

**macOS 提示无法打开、无法验证开发者**：项目没有付费的 Apple 开发者账号，安装包没有经过 Apple 公证。打开「系统设置 → 隐私与安全性」，在页面下方点「仍要打开」。macOS 15 起，右键「打开」已经跳不过这一步。如果提示「已损坏，无法打开」，在终端运行下面这行再打开：

```bash
xattr -dr com.apple.quarantine /Applications/Whisper.app
```

**Android 安装被 Play 保护机制拦截**：按提示选择「仍然安装」。没有这个按钮时，在 Play 商店点头像，进入「Play 保护机制 → 设置」，暂时关闭「使用 Play 保护机制扫描应用」，装完再打开。

**Android 13 及以上，打开通知转发时开关是灰的**：这是系统对安装包的「受限设置」。在系统设置的应用信息里找到 Whisper，点右上角的 ⋮，选「允许受限制的设置」，再回来打开。

## 找不到设备、连不上

**按连接诊断的提示处理**：

| 诊断结果 | 怎么办 |
| --- | --- |
| 无法到达该设备 | 两台设备要在同一个网络。访客 Wi-Fi、开了 AP 隔离（也叫客户端隔离）的路由器，以及很多公司和学校的网络，不允许设备之间直接通信。可以关掉隔离，或者都连到同一个手机热点 |
| 二维码中的地址无效 | 让对方重新打开二维码再扫 |
| Whisper 服务没有响应 | 在对方设备上打开 Whisper；对方改过「服务端口」时，按新端口连接 |
| 连接超时 | 多半是防火墙，见下面的 Windows 防火墙 |
| 设备身份与二维码不一致 | Whisper 已停止连接。请对方重新出示二维码，不要绕过这项检查 |
| 协议版本不兼容 | 两台设备都更新到同一个新版本 |
| 配对未完成 | 两边都开着 Whisper，重新核对配对码 |

**Windows 防火墙**：第一次打开 Whisper 时，Windows 会询问是否允许它访问网络，要勾上「专用网络」。如果当前网络被设成了「公用网络」，Windows 会挡住别的设备连进来。可以在「设置 → 网络和 Internet」里打开当前网络的属性，把网络配置文件类型改成「专用网络」；或者在「允许应用通过 Windows 防火墙」里给 Whisper 勾上「专用」。

**macOS 的本地网络权限**：macOS 15 起，程序访问局域网要单独授权。打开「系统设置 → 隐私与安全性 → 本地网络」，确认 Whisper 是开着的。

**代理和 VPN**：Clash 等工具的 TUN 模式、增强模式，以及公司 VPN，可能接管局域网的流量。把局域网网段设成直连，或者暂时关掉再试。

**列表里没有对方，但网络是通的**：路由器或网络可能屏蔽了组播，自动发现就找不到设备。直接用二维码或地址连接：桌面端点左下角这台设备的名字，选「输入地址…」；手机点加号。默认端口是 `10002`。Linux 的自动发现依赖 Avahi。

**电脑上有 Hyper-V、WSL、Docker 或虚拟机**：这些会多出几块虚拟网卡，二维码里的地址可能不是你要用的那块。用「输入地址…」填对方真正所在网段的地址。

**本机服务没有起来**：诊断信息里会显示端口被占用之类的原因。在「设置 → 连接 → 服务端口」里换一个端口，退出设置后生效。

## 连上后又断开

**Android 在后台被系统清掉**：
- 在「设置 → 连接」里打开「后台保持连接」，并把 Whisper 加进「电池优化白名单」。
- 很多品牌的手机还有自己的后台限制。在系统设置的应用管理里找到 Whisper，把耗电设成「无限制」或「允许后台活动」，并允许自启动。
- 在最近任务里锁住 Whisper 也有帮助。

**Mac 睡眠**：Mac 睡眠前，Whisper 会主动断开连接，免得别的电脑把指针移到一台睡着的 Mac 上。醒来后，如果开着「设置 → 连接 → 自动连接已配对设备」，会自动重新连上。

**Windows 上指针一顿一顿，或传输时快时慢**：检查「设置 → 系统 → 投影到此电脑」。打开它时，无线网卡要同时维持一个 Wi-Fi Direct 网络，Wi-Fi 会周期性地变慢。不用无线投屏的话，设成「始终关闭」。

## 键鼠共享

**指针留在另一台设备上回不来**：在主控端按 `Ctrl+Alt+Esc`，macOS 上是 `Control+Option+Esc`。

**macOS 上没有反应**：在「系统设置 → 隐私与安全性 → 辅助功能」里打开 Whisper，然后退出并重新打开 Whisper。如果是更新之后突然失灵，而列表里的 Whisper 看起来还开着，先用「−」把它删掉，再重新添加并打开。

**Windows 上，任务管理器等以管理员身份运行的窗口在前台**：普通程序操作不了这类窗口。要用到安装包附带的系统服务，还要打开它那一行末尾的开关，见使用指南的 [Windows 锁屏与 UAC](user-guide.md#windows-锁屏与-uac)。没打开开关时：
- 这台电脑被控制：指针会自动回到主控端。
- 这台电脑在主控：指针移不到别的设备，屏幕上会提示先单击一下再移过去。

**Wi-Fi 下指针一顿一顿，或声音断断续续**：
- 两台电脑都更新到 0.0.60 或更新的版本。新版的键鼠和声音走 UDP，不会因为偶尔丢一个包就停住。
- Windows 防火墙要允许 Whisper。第一次打开时的询问会同时放行 TCP 和 UDP；如果只放行了 TCP，功能照常，但弱网下又会卡。
- 看设备卡片里的「网络」：丢包多、延迟波动大时，换 5 GHz 的 Wi-Fi、靠近路由器或插网线。同时传大文件时，Whisper 会给键鼠和声音让路，传输会慢一些。

**锁屏界面**：Windows 需要系统服务，见上面同一节。电脑重启后还没登录时，Whisper 没有运行，无法控制。

**Linux**：Wayland 下的支持情况和授权方式，见使用指南的 [权限与平台限制](user-guide.md#权限与平台限制)。

## 声音、窗口流转和截图

**macOS 上共享不了声音、流转窗口没有画面、截不了图**：这几项都要「屏幕录制」权限，macOS 15 起叫「屏幕与系统录音」。在「系统设置 → 隐私与安全性」里打开 Whisper，然后重新打开 Whisper。

**Linux 上流转窗口没有画面**：需要 Wayland 会话和带 H.264 编码器的 FFmpeg，GNOME 还要装设置里的组件。详见使用指南的 [被流转的设备](user-guide.md#被流转的设备)。

## 剪贴板

- 剪贴板同步默认是关闭的，要在两台设备上都打开。
- Android 只同步文本。Android 10 起后台程序读不到剪贴板，回到 Whisper 后会自动补发。
- 在 macOS 和 Windows 上，密码管理器复制的内容不会同步。这是有意这样做的。

## 提交问题

上面都试过还不行，就[提交问题](https://github.com/lawnvi/whisper/issues/new/choose)，选「中文」：

1. 在设置里打开「诊断信息」，点「反馈问题」。诊断信息会被拷贝，同时打开 GitHub 的问题表单。
2. 把诊断信息粘贴进去，写上两台设备的 Whisper 版本和系统版本，以及怎么复现。
3. 如果连接诊断有结果，附上截图。

诊断信息不含消息、文件和设备名，只有系统版本、本机网络地址和运行记录。
