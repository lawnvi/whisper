# 各界面规格

全局规则和 token 在 [`DESIGN.md`](../../DESIGN.md)。这里写每个界面的结构、尺寸、状态和文案。[原型](whisper-ui-language.html)是质感和手感的参照，[截图](reference/)是静态参照。两者不一致时以本文为准，并修正原型。

尺寸单位都是逻辑像素。`触控` 指手机、平板和折叠屏，和窗口多宽无关。

**现有功能清单**是底线：重做时这些操作不能少。原型为了聚焦，有些没有画，以清单为准。

## 窗口外壳（桌面）

截图：`desktop-chat.jpg`、`windows-chat.jpg`、`gnome-chat.jpg`、`kde-chat.jpg`

```
┌────────┬─────────────────────────────────────┐
│ 侧栏    │ 工具栏（52）                         │
│ 252    │ 内容                                 │
│ 玻璃    │ 实色          设备卡片 296，盖在上面    │
└────────┴─────────────────────────────────────┘
灵动岛在整个窗口的上方正中
```

- 窗口圆角 `m`，`e3`。
- 尺寸类：常规（600 到 1000）和宽（≥1000）都是侧栏加内容，设备卡片都盖在内容上，见「设备卡片」；紧凑（<600）见「手机」。
- 工具栏和内容同色，不画线。内容滚动后下方出现 0.5 的 `sep`。内边距左 20、右 12。标题 `head` 半粗，最多占 34% 宽度，超出截断。
- 最小 720×480。现有 App 没有设最小尺寸，用 `windowManager.setMinimumSize`。
- 所有桌面平台都隐藏系统标题栏（现在是 `TitleBarStyle.normal`，`lib/main.dart:136`，要改成 `hidden`），工具栏和内容融为一体。

**窗口按钮**：`WindowButtons`（`flutter.md`），画在窗口最上层，遮罩和弹层都盖不住它，和系统自己的按钮一样。

| | 样子 | 位置 |
|---|---|---|
| macOS | 红绿灯，系统画，大小跟系统（macOS 27 实测直径 14、圆心距 23），距边 16 | 侧栏左上，工具栏中线上 |
| Windows | 46×32 的方块，图标 11，悬停 `fill`，按下 `fill2`。关闭悬停 `#C42B1C` 白叉，按下 `#B02A1C` | 贴右上角，距顶 0 |
| GNOME | 直径 24 的圆，底 `fill`，悬停 `fill2`，按下 `ink3`，圆之间隔 8，图标 14。命中区 32 | 圆距顶 14、距边 12，和工具栏同一条中线 |
| KDE | 直径 24，平时没有底，悬停 `fill2`，关闭悬停 `#DA4453` 白叉，圆之间隔 4，命中区 28。最小化是向下箭头，最大化是向上箭头，还原是菱形（Breeze 的习惯） | 同 GNOME |

- 悬停的颜色直接变，不走弹簧，系统按钮就是这样。不进 Tab 顺序，Alt+Space、Alt+F4 这些系统快捷键负责键盘操作。读屏名称：最小化、最大化或还原、关闭。
- **按钮在左**：GTK 的 `gtk-decoration-layout` 决定两边各放什么。Ubuntu 是 `:minimize,maximize,close`，原版 GNOME 是 `appmenu:close`（只有关闭），有人设成 `close,minimize,maximize:`（全在左）。左边的按钮放在侧栏顶部，右边的放在工具栏右上。设置改了要实时跟着变。
- **工具栏留位**：右内边距 = 12 + 按钮总宽（`WindowButtons.widthOf`）。设备卡片盖在上面时也不变，下面什么都不动。
- **设备卡片和弹层让开**：设备卡片距顶 40（Linux 44）。设置等所有弹层上下一共留 96（按钮在右边的 Linux 104），窗口按钮和灵动岛都不压在弹层上。按钮只在左边时卡片恢复默认。
- **最大化**：圆角变成 0，图标换成还原。双击工具栏或侧栏顶部的空白也能切换。
- **关闭**：沿用现有逻辑，开着「关闭时隐藏到托盘」就隐藏，否则退出。
- **失去焦点**：云母由系统退成纯色，不用处理。

## 侧栏

截图：`desktop-chat.jpg`、`desktop-offline.jpg`

玻璃 `sidebar`，右边 0.5 的 `sep`。列表内边距 8 / 10。

**顶部**（高 32）：搜索、声音、键鼠三个 28 的图标按钮，靠右。声音和键鼠正在进行时图标是 `accent`，当前打开时底色 `selected`。不放常驻搜索框。Windows 和 Linux 左上角没有红绿灯，写 App 的名字「Whisper」（`note` 中等 `ink2`，左边距 20），上内边距 10，让这一排和工具栏同一条中线。按钮放在左边时不写名字。

**设备列表**：一个列表，不分组。顺序用 `StableDeviceOrder`（`flutter.md`）：

- 始终三档：连着的、附近的（配对过和没配对的放一起）、不在附近的。
- **变差下移**：断开或下线时移到新档位的最前面，走 `smooth`。离线的不会排在在线的上面。
- **变好上移**：连上或被发现时移到新档位的最后面，走 `smooth`。新设备同样。不会把上面的行顶下去。
- 不按最新消息跳动。

**设备行**：高 60（触控 72），内边距 0 / 10，行距 2，圆角 `m`。悬停 `fill`。左边是直径 38 的圆（触控 48），写名字的首字，白色半粗：连着的 `#03A9F4`，附近的 `#4CAF50`，离线的 `#E0E0E0`。名称 14 半粗（触控 17），`deviceName`，有消息时第一行右边是最后一条的时间 11（触控 12），`deviceMuted`。第二行一个 7 的状态点加状态 12（触控 13），`deviceMuted`。系统靠悬停提示，设备页和卡片还是写实设备图。手机的行没有分隔线。

**选中底**：一个元素，不是每行各画一个。8% 的蓝（`deviceSelected`），没有投影。切设备时走 `snappy` 滑到新的行，中途再切会接着滑。进共享页时淡出，回来时直接到位再淡入。

第二行按优先级取第一个成立的：

| 情况 | 文字 | 颜色 |
|---|---|---|
| 正在连接 | 正在连接… | `ink2` |
| 没配对、在附近 | 在附近 · 可以配对 | `ink2` |
| 配对过、在附近、没连接 | 在附近 | `ink2` |
| 离线 | 离线（没有消息时带上次出现的时间） | `ink3`，名字也退到 `ink2`（玻璃上 `ink2Glass`）；选中时不退 |
| 正在传输 | log.txt 59% | `accent`，中等字重（手机上也一样，下同） |
| 它把声音放到这台 | 声音放到这台 | `accent` |
| 它在控制这台 | 正在控制这台 | `accent` |
| 指针在它那里 | 键鼠正在控制它 | `accent` |
| 放着这台的声音 | 放着这台的声音 | `accent` |
| 有流转窗口 | 2 个窗口 | `accent` |
| 其他 | 最新一条消息或文件名 | `ink2` |

选中行上状态的颜色不变。设备图：**有颜色就是在，灰的就是不在**，一眼分得开。连着的是原本的颜色，没配对的是浅蓝壁纸，配对过、在附近但没连接的只淡一点（饱和 0.85，不透明 90%），离线的灰度加半透明（45%）。手机同样。

**左下角**：内边距 6 / 8 / 10 / 10，最小高 46。这台的设备图标（18）和名字（`note` 中等，占剩余宽度，超出截断），右边紧挨着 2 个 28 的图标按钮：共享链接、设置。连接新设备就是点名字，不再单放一个加号。共享链接正在进行时图标是 `accent`，当前打开时底色 `selected`。

**这台面板**（点名字，桌面是弹层）：设备图 96、名字、二维码 148、「另一台设备扫这个二维码就能连上这台」、地址、身份指纹、输入地址…、完成。发现不了时不显示二维码，写「这台不在局域网里，其他设备发现不了它」。局域网断开时左下角图标变 `warn`，灵动岛提示，布局不动。

**右键设备行**（手机在设备页）：断开连接或连接、设备卡片、离线时移除这台设备。

**只有这台时**（附近和配对过的设备都没有）：`ShellFirstDevice`，页头的样子。这台设备的写实图（壁纸是这台的），三个点，一台灰色的另一种设备（手机旁边是笔记本，电脑旁边是手机），灰色的意思和别处一样：不在。下面是标题、一句话说明另一台怎么出现、「连接设备」。手机放在列表位置；平板和桌面放在内容区，侧栏留空，不重复。有设备出现时淡出。

现有入口：`lib/page/deviceList.dart`，分组数据来自 `ChatSessionListBuilder`。

## 设备页

截图：`desktop-chat.jpg`、`desktop-files.jpg`、`desktop-apps.jpg`、`desktop-tab-switch.jpg`

工具栏：名称，右边分页胶囊（对话、文件、应用，高 30）和信息按钮（打开时 `accent` 加 `fill` 底）。不写「已连接」。

分页切换用 `LiquidSegmented` 和 `WhisperTabView`（`flutter.md`），规则见 `DESIGN.md`「动效」。默认分页：记住每台设备上次的分页，第一次进对话。

**分页第一次显示时才创建**，之后留着，输入框内容和滚动位置都在。`RemoteFilesPage` 一创建就会向对方请求访问，所以不能提前创建。

**切设备、进共享页、开设置**不是分页切换，没有方向：内容从下方 5、透明，走 `smooth`，侧栏不动。切设备时分页内容重建，草稿沿用现有逻辑（`SendMessageScreen`）。

没连接（文件、应用）：垂直居中，设备图 84、「iMac 没有连接」（`title`）、一句话、连接按钮（`lg` 填充）。连接中按钮写「正在连接…」。

没连接（对话）：能看历史，**不显示输入框**，要连接点工具栏的图标。

**工具栏右边是一个和分页同样形式的胶囊**：同样高（指针 30，触控 36）、同样的 `fill` 底、同样的胶囊圆角，里面两个图标格（点击区触控 48）。连接或断开（`power`，指针 15，触控 19）：没连时 `accent`，连着时 `bad`，连接中是小转圈不能点。设备卡片（信息，手机是 `⋯`）：`ink`，打开时格子是 `raised` 底加 `e1`，和分页的滑块一样。悬停写全名。图标不单独散放在分页旁边。

**草稿**：写了没发的文字、剪贴板文件和图片按设备留着，换设备、去声音页或设置再回来都还在。只存在内存里，不写磁盘，应用退出就没了。

**发送剪贴板**：对方的剪贴板变了这边看不到，所以按钮自己回答：图标变成 `ok` 的勾，1.4 秒后变回。剪贴板是空的或者没发出去时不变勾，说原因。

没配对：设备图 84（灰色壁纸）、「2698b 在附近」、「请确认两台设备显示相同的 6 位数字」、数字（等宽 30 半粗）、「数字相同，配对」。

## 对话

截图：`desktop-chat.jpg`、`desktop-composer-shot.jpg`、`phone-chat.jpg`

列表铺满内容区，内边距 8 / 16 / 84（触控 8 / 12 / 92）。

- **气泡**：对方 `bubble` + `ink`；我发的 `tint-hover` + `on-tint`。内边距 7 / 13，圆角 18，`body`，行高 1.45。宽度上限：指针 min(72%, 30 个字宽)，触控 80%。**折行后也收到最长一行**，见 `WhisperBubble`。
- **间距**：同一人连续 8，换人 16。时间 `tiny` 居中，上 14 下 8。
- **文件卡**：宽 min(276, 82%)，内边距 10 / 12，圆角 18，底色 `bubble`，靠对应一侧。白纸图标 30，文件名单行，下面大小和进度，次要字用 `ink2-glass`。传输中多一条进度条和取消，完成写「已送达」。出了问题：`warn` 小图标加一两个字的 `warn` 词（「发送失败」「接收失败」「已删除」），后面的原因或大小仍用次要色；主动取消的只写「已取消」。手机长按菜单不放「所在文件夹」（手机没有统一的文件管理器），文件不在这台设备上时也不放「打开」和「分享」。
- **发出的消息**从输入框升起：从下方 26、缩放 0.9、透明，走 `smooth`，变换中心在右下。

**气泡上的复制（指针）**：鼠标在文字消息的气泡上时，气泡旁边浮出一个复制图标，没有底色，和气泡底边对齐：对方的消息在气泡右边，自己的消息右边就是窗口边缘，所以在左边。不挤动任何东西，点了变成勾一会儿。手机没有，长按菜单里有。**最后一条消息**离底部多留一点：输入框上方 24（触控 16），没有输入框时 32。

**输入框（指针）**：`control` 玻璃卡片，圆角 `l`，阴影只画在外面（`WhisperOutsideShadow`，否则这么大一块玻璃会发灰）。居中，宽 min(860, 100% − 48)，距底 16，内边距 5。默认两行，向上长高，最多 6 行，再多在框里滚动。**最下面一行是工具栏，位置永远不变**：左边截图、发送剪贴板，右边 `+`（文件、文件夹）、发送键（28）。发送键没内容时是中性底，有内容时变 `accent`。点卡片任何地方都是在写字。粘贴的预览长在文字上方，点小图进入标注。

**输入框（触控）**：`control` 玻璃胶囊 + `e2` + 高光。宽 100% − 36，距底 24，内边距 5。**框里不放占位文字**（读屏时仍然说「发给 iMac」）。**空的时候**一行：发送剪贴板、`+`。**开始输入后功能键收起**（横向收拢，走动效），文字占满，只留右下角一个发送键，和常见聊天软件一样；框向上长高，最多 5 行，再多在框里滚动，发送键一直贴在右下角。按钮不换行、不跳动。清空后功能键回来。空的时候从左到右：

1. 输入框，占位「发给 iMac」，名字太长时省略。
2. 发送剪贴板（28 图标按钮）。
3. 截图（只有桌面）。现有规则不变：框选后进剪贴板，粘贴到输入框预览再发。截图和粘贴的预览以 22 的小图 + 名字 + 移除，放在输入框左边。
4. 发送键（28，触控 38）：没内容时是中性底的 `+`，点开菜单选文件、文件夹（手机是文件、照片）；有字或附件时变 `accent` 底的箭头，两个图标旋转 90° 交叉过渡。

**诊断信息**：Whisper 没有正常运行时（数据库打不开、启动失败或 20 秒没完成、连接服务或发现设备没起来），灵动岛一直显示「Whisper 没有正常运行」和原因，带「查看」，修好才消失。设置的「关于」里也有入口。弹层列出数据库、连接服务、发现设备的状态和本机地址，出问题时写明影响，可以拷贝，或反馈问题（先拷贝，再打开 GitHub，贴进去就行）。内容不含消息、文件和设备名：系统版本、本机网络地址和运行记录。运行记录在 `AppLog`：只收 `PrivacyLog` 放行的事件和错误的类型、代码、位置，不收错误原文，两个文件各 512 KB 封顶。

**设备行的「正在连接」**：只在第一次自动连接时显示。对方连不上（比如手机系统把后台的 Whisper 冻结了）就回到「在附近」，继续在后台悄悄重试，连上了才变。不会一直显示正在连接。

**本机**：和这台设备自己的会话，附近没有设备时也能用，什么都不会发出去。只有连接时输入自己的地址才进入，这台面板和首页都不放入口：它是彩蛋，不是必要的功能。打开过才出现在列表里，排在连着的设备后面，第二行是最新一条，没有时写「只保存在这台设备上」。工具栏只有名字：没有分页、连接和信息。可以发文字、文件和粘贴的图片；临时目录里的图片（截图）拷到接收目录，其他文件只记路径。发文件夹不支持。右键只有删除，只删这个会话，不碰发给别人的消息。

**截图**：快捷键按下屏幕立刻定格，拖动或单击窗口选区，由各平台的原生窗口负责。按下快捷键时就开始准备应用自己的一个窗口（`capture_overlay.dart`，独立引擎），整屏画面在框选期间已经画好，只是看不见；松手的瞬间它盖上来，画面一个像素都不动，工具栏直接出现在选区右下，没有中间步骤。截图结束窗口和引擎就销毁（Mac；其他平台清空后隐藏），不常驻内存。放不下时在选区上方，全屏选区时在选区里面。工具栏是 `control` 玻璃：工具（框、圈、箭头、画笔、文字、马赛克）、撤销、重做、取消、存为文件、复制；选了工具才在下面多一条粗细和颜色（马赛克没有颜色）。

没选工具时拖选区内部是移动，拖边和角是调整，拖选区外面是重新框，双击选区内部或 Enter 是复制。选了工具后在选区内画（画的东西不出选区），再点一次工具放下。按住 Shift 画正方形、正圆、八个方向的箭头。⌘Z 撤销，⇧⌘Z 重做，Esc 或右键取消。输出和屏幕同样的像素，不重采样；马赛克用整屏缩小后的色块画，不含底下的原始像素。Whisper 的主窗口全程不出现，也不抢前台。

例外：选区跨两块屏幕时原生窗口保留原来的取消和复制（一块屏幕一个窗口，画不了跨屏的）。Wayland 由系统选区，选完进剪贴板，粘贴到输入框后点小图进入标注（`capture_editor.dart`，同样的工具，在 Whisper 窗口里）。窗口起不来时也退回这一页。

**现有功能放在哪**（原型没有画，按这里做）：

| 功能 | 新位置 |
|---|---|
| 消息菜单（右键，手机长按） | 复制、打开、所在文件夹（桌面的文件）、重试（失败时）、选择、删除 |
| 多选 | 进入后工具栏分页换成「已选 3 项」和「取消」，输入框位置换成同样玻璃的操作胶囊：全选、复制、删除 |

1. **头部**：写实设备图 104、名称（`title`）、状态（`note`）：已连接、还没有配对、正在连接…、离线 · 时间。

   - 挂载：开关，只有桌面。

## 声音

截图：`desktop-audio.jpg`、`desktop-audio-idle.jpg`、`desktop-audio-sink.jpg`、`dark-audio.jpg`

**事实**（`lib/audio/audio_group_coordinator.dart`）：

- 只能由来源发起。协议只有来源到接收端的邀请，接收端能暂停、重新加入和断开。
- 一台设备同时只有一种角色。接收端只能加入一个来源。
- 每个成员有声道（立体声、单声道、左、右）和状态，独立失败。
- 没有按成员调音量的协议。增益只影响接收端自己。

**页面**（电脑），侧栏顶部进入，背景 `canvas`，内容列最宽 520，居中，左右 20，下 28。上边距只看窗口高度（(高 − 300) / 3，最多 160），不看内容：窗口高时不头重脚轻，设备增减时什么都不动。

1. **设备图就是播放按钮**：这台的设备图 144，屏幕上不画系统元素，只有壁纸和一个 40 的圆形按钮，整张图都能点。下面是这台的名字（`title` 半粗）和它在做什么（`body` `ink2`，一行）：未播放、正在播放到 2 台设备。不写操作说明。
2. **勾选列表**（内缩分组，分隔线缩进 60）：**只列连着的设备**，点不了的不占地方。每行高 60：设备图 36（占 38 宽）、文字、声道、右边圆形勾选 22。第一行是名称（`body`，太长就截断）加同步质量（`note` `ink2`，有问题时 `warn`，不截断），第二行是具体数字「网络 2ms · 抖动 1ms · 缓冲 80ms · 晚包 0」（`note`，等宽数字），或者不能放的原因（只能单独放、失败原因）。
3. **声道收在弹出按钮里**：写当前声道，点开带勾的菜单（左声道、立体声、右声道、单声道）。**勾选了两台以上才出现**，一台没有声道可选。

**总开关**就是设备图上的按钮：能放时白底 `accent` 的播放；放着时按钮里是跳动的声波（`accent`），指针移上去变成暂停；没有勾选设备、一台都没连着或没有权限时是半透明白、不能点。在列表上面，设备再多也看得到。关闭后成员留着。

**状态行**：名字下面一行，高至少 30，旁边有按钮时也不变高，所以下面不动。没有权限、开始失败时用 `warn`，一台都没连着时写「没有已连接的设备」。同步情况写在每台设备的行里，不再汇总。

**声道默认值**：第一台立体声。第二台加入时，如果用户没动过声道，自动分成左右。剩一台时回到立体声，不管动没动过。第三台起立体声。

| 一台都没连着 | 不能点 | 没有已连接的设备 | 不画列表 |
| 没有成员 | 不能点 | 未播放 | |
| 勾选了，还没开始 | 播放 | 未播放 | 已停止 |

**接收端的增益行**：内缩分组，最宽 320，居中，比上面的页头和下面的按钮不宽太多。标签和滑块紧挨着（间距 12），滑块占剩下的宽度，右边写「1.0x」。不铺满内容列，不要标签在最左、滑块在最右（截图 `desktop-audio-sink.jpg`）。手机进不了声音页，所以手机的设置里还留着这个滑块。

| `offered`、`accepted`、`connecting` | 正在连接… |
| `active`，还没有同步数据 | 不写 |
| `active`，有数据 | 同步良好、同步一般、同步波动，后两个用 `warn`。判断逻辑沿用 `_audioGroupSyncQualityLabel`（`lib/page/deviceList.dart`）：有晚包、误差超 30ms 或抖动超 20ms 是波动，误差超 12ms 或抖动超 8ms 是一般 |
| `active`，声音到不了它 | 收不到声音（`warn`），下面不写数字。这台一直在发、它 3 秒没有回报（开始发或从无声恢复后先等 3 秒），或它回报的缓冲超过 250ms（超出它能放的，包在到期前就被挤掉）。回报只在收到包时才发，停了不会自己说，所以这台每半秒看一次 |
| `lagging` | 同步波动 |
| `failed` | 没有放出来，选中看原因。`lastError` 是 `AudioFailureReason` 的名字，用 `audioFailureReasonFor` 和现有的 `_audioFailureDetail` 转成文字 |
| `stopped` | 已断开。对方暂停或断开都是这个状态，可能回来（`sinkJoinRequest`），留在列表里，保持勾选 |

**不支持组播放的旧设备**（`supportsAudioGroupSinkFor` 为假）也列出来，只是它不能和别的设备一起放：没有声道控件，下面写「只能单独放」。勾选它时取消其他成员，走 `AudioShareCoordinator.startSharingToConnectedPeer`；已经单独放给它时勾选别的设备，先停止它。

**没有权限**（`AudioFailureReason.permission`，macOS 上是屏幕与系统录音）：状态行写「需要允许屏幕与系统录音」，旁边一个「去开启」按钮，打开系统设置；设备图上的按钮不能点。此时列表可以勾选，但不开始。

**当前平台不能采集**：不显示这一页的入口。


**接收端的细节**，来自 `AudioIslandSource`：

| 情况 | 能做什么 |
|---|---|
| 组播放，放着 | 暂停、断开 |
| 组播放，已暂停，来源支持重新加入（`audioGroupRejoinV1`） | 继续、断开 |
| 组播放，已暂停，来源不支持 | 只能断开，不显示继续 |
| 继续中 | 副标题「正在恢复…」，按钮禁用 |
| 旧版一对一来源 | 只能断开，没有暂停 |

**手机**只有接收端，没有这一页，控制在灵动岛和那台设备的设备页。

**增益要改代码才能实时生效**：现在组播放只在开始时读一次（`lib/audio/audio_group_coordinator.dart:1384`）。接收端的滑块拖动时要立刻起作用，这是新工作，给协调器加一个设置增益的方法。

现有入口：`lib/page/deviceList.dart:2414` 和 `lib/page/conversation.dart:1973` 各有一个设置面板，合并成这一页。不支持组播放的旧设备走 `AudioShareCoordinator` 的一对一，界面不区分。

## 键鼠

截图：`desktop-input.jpg`、`desktop-input-on.jpg`、`desktop-input-drag.jpg`、`desktop-input-controlled.jpg`、`dark-input.jpg`

**事实**（`lib/remote_input/`）：

- 只能由控制端发起。正在被控制的设备不能再发起。
- 每台设备可以有多块屏幕，布局保存，自动吸附，屏幕之间形成路由。
- 状态：等待确认、已就绪、控制中、失败（`RemoteInputWorkspaceTargetStatus`）。连接后的失败每个目标独立。
- **但未互信或对方不能被控制时，`startControllerWorkspace` 和 `updateControllerWorkspaceRoutes` 整体失败**。所以开启前先用 `RemoteInputWorkspaceTargetRequest` 的 `isMutuallyTrusted`、`remoteCanInject` 过滤，把这些设备标成「没有连上」，其他的照常开始。重试就是带上它再调一次 `updateControllerWorkspaceRoutes`。
- 指针在别的设备上时，这台的界面点不到，所以**没有「回到这台」按钮**，只有快捷键和推回来。
- 退出快捷键 `Ctrl+Alt+Esc`（macOS `Control+Option+Esc`），对方断开时指针自动回来。
- **Windows 上的管理员窗口**（任务管理器等提权程序）：Windows 不让普通程序给它送键鼠，也不让普通程序听见它在前台时的鼠标。装了键鼠服务并打开「锁屏与 UAC 时接收键鼠」里允许 UAC 的开关时，两个方向都照常：被控时由服务送键鼠；当控制端时，推到共享的那条边，服务放行，Whisper 拿到前台再过去，过去期间盖一层几乎透明的窗口防止点击漏到管理员窗口上，回来时把前台还给它。服务是旧版（需更新）时，推到边上旁边出一个黑色胶囊「前面是管理员窗口：单击一下，再移过去」（`inputElevatedHint`），单击一下就能过。开关关着时被控端把指针交还，不会卡住。窗口流转操作管理员窗口时把它提到前台，用真实的键鼠。
- 手机不能当被控端。

**页面**（电脑），侧栏顶部进入，像系统设置的显示器排列。工具栏右边是总开关。内边距 0 / 20 / 14，分块间距 14。

1. **画布**：占满剩余高度（最少 240），圆角 `m`，底 `fill`，内阴影 `inset 0 1px 3px rgba(0,0,0,.05)`。内容按比例缩放居中，四周留 28，每逻辑像素最多 0.13。屏幕增减时缩放走 `smooth`。
2. **屏幕块**：按真实比例。圆角 `xs`，壁纸渐变，顶部 7%（至少 4）的白色半透明菜单栏，整体压一层渐暗，阴影 `0 2px 8px rgba(0,0,0,.2)`。多块屏幕分开画，间隙 2。名字在中间（`note` 半粗，白字），下面一行状态只写：等待确认、无法控制（连着但键鼠没起来，原因在底部）、正在控制。屏幕太矮（<44）时不显示状态。
3. **候选**（画布下方，有才显示）：胶囊，高 34，白底 `e1`，32×22 的迷你屏幕加名字。**拖到画布或点一下就加入**，拖出画布就移出。**只列连着的设备。**
4. **底部**（最小高 28，`note`）：
   - 没选中、没开启：「拖动屏幕来排列。指针从相接的边过去。」
   - 没选中、开启：「按 ⌃⌥Esc 收回键鼠」，这是安全出口，不能省。
   - 选中屏幕：名字、分辨率、「在右边」，失败时写原因和「重试」，右边「移出」。

**交互**：

- 屏幕是素的：这台 `tint`，其他 `raised`，细边框，文字 `ink`，不画壁纸。选中时边框就在屏幕上，2 粗 `accent`，不留间隔。
- 拖动时屏幕抬起（投影 `0 14px 22px rgba(0,0,0,.3)`），跟手（`follow`），显示吸附预览（`accent` 22% 底、1.5 描边）。放下用 `snappy` 贴到预览位置。键盘：方向键移动 100 逻辑像素，Shift 400，Enter 选中。
- **屏幕不会悬空**。只能贴在指针走得到的屏幕旁边（从这台开始，经过相接的在线屏幕能到达）。挪走一块后，接在它旁边的屏幕自动贴回去。所以正常操作里不会出现「边缘重叠」和「没贴边」的错误。复用 `RemoteInputWorkspaceSnapper` 和 `RemoteInputWorkspaceMagnetizer`。
- 没连着的设备不显示。它的位置保存着，连回来时回到原位；原位被别的屏幕占了就贴到旁边。
- 选中的屏幕有外圈：外扩 3，2.5 的 `accent`。
- 总开关明确开启，不像声音那样点了就开始，因为它会接管指针。开启后画布里有真实的箭头指针（15×21），显示它现在在哪台。
- 一台失败不影响其他：`没有连上`，选中它看原因（比如「它还没有信任这台」）和重试。

**被控端**：「iMac 正在控制这台」、设备图 96、停止。滚轮速度在设置里。判断用 `RemoteInputCoordinator` 的 `state.role == RemoteInputRuntimeRole.sink`，停止用 `stopSharing`。（`RemoteInputWorkspaceRole.controlled` 没有被赋值过，不要用。）

| 异常 | 显示 |
|---|---|
| 没有可控制的电脑 | 画布上只有这台，底部写 `remoteInputWorkspaceNoTargets`，总开关禁用 |
| 这台没有权限（macOS 辅助功能，设置页） | 底部写原因和「去开启」，打开总开关不生效 |
| 这台不支持（`supportsNativeRemoteInput` 为假） | 侧栏顶部没有键鼠入口 |
| 对方版本不支持 | 候选里禁用，写「不支持」 |
| 对方没有信任这台（`remoteInputPeerMustTrustThisDevice`） | 屏幕写「没有连上」，选中看原因 |
| 冲突 | 布局自动贴回后不应出现；如果对方上报的屏幕变了，自动重排一次 |

入口：`lib/new_ui/input/shell_input_page.dart`，数据 `RemoteInputWorkspaceCoordinator` 和 `RemoteInputWorkspaceSnapshot`。

## 共享链接

截图：`desktop-links.jpg`、`desktop-link-detail.jpg`、`phone-links.jpg`

**不依赖任何设备，也不需要先连接。** 对方不用装 Whisper。桌面左下角进入，手机在设置里。

**现有功能清单**（`lib/page/remote_files/files_shares.dart`、`lib/share_links/`），全部保留：

- 创建：不问问题，直接用默认的随机路由、不设密码建好，打开详情。路径和密码在详情里改。入口有两个：这里的新建（用系统文件选取器，可以选多个文件或文件夹）、「文件」位置切到这台后选中文件的共享链接。
- 每条：名称、路由、状态、访问次数、下载次数、最近访问。文件不见时要提示。
- 操作：拷贝、二维码、开启或关闭、删除（要确认，说明不影响本机文件）。
- 文件服务：本机地址、端口、总开关、失败重试。只在有链接开着时运行。多个网络时可以切换链接地址。

**页面**：背景 `canvas`，内容列最宽 620。工具栏右边新建（手机是 `+`）。

- **文件服务**（固定在最上面，不随列表滚动，链接多了也够得着）：标题，下面地址或「没有开启的链接，服务没有运行」或「链接都打不开」，右边总开关。
- **列表**：一个白色分组，**不画线**，行高 60，内边距 8 / 14，间距 12。每行：文件或文件夹图标 28（关着时透明度 0.45，名字变 `ink2`）、名称（有密码时加 11 的小锁）、统计、开关。桌面悬停时在开关左边出现「更多」（拷贝链接、二维码和详情、删除链接…），开关都靠右对齐。
- **统计行**：`12 次访问 · 5 次下载 · 今天 17:20`；关着写「已关闭」；服务关着写「文件服务已关闭」；文件不见写「有些文件不在原来的位置了」，前面 12 的 `warn` 小图标，文字仍是 `ink2`。
- **没有链接**：图标 40、「还没有链接」、一句话、「选择文件夹」和「选择文件」。
- **新建**：菜单，选择文件或选择文件夹。

**新建**：macOS 的系统面板能同时选文件和文件夹，所以只有一个按钮「选择」，可以多选。其他系统的面板分开，还是文件和文件夹两个入口，文件可以多选。选好后先问路径（可以不填，4 个字符的简短路径是个开关）和密码（可以不填，右边的眼睛闭着是隐藏、睁开是显示），再进详情。

**详情**（点一行，弹层，手机是底部弹层）：名称、二维码、地址框（等宽）、分组（开启、地址、路径、密码、访问、下载、已发送。这台有多个网络时地址点开能换。路径和密码点开能改，改路径后旧地址失效，改密码后已经进来的人要重新输）、删除链接（无底 `bad`）、拷贝链接、完成。创建成功后直接进这里。

**新建**（弹层）：「共享「文件名」」、路由（占位是随机路由）、简短路由开关、密码（可不填）、取消、创建链接。路由重复时输入框报错。

**删除确认**：「删除「文件名」？」「这个地址会打不开。本机的文件不受影响。」取消、删除（`bad` 填充）。

## 托盘

截图：`desktop-tray-hold.jpg`、`desktop-tray-clips.jpg`、`desktop-tray-copied.jpg`、`dark-tray.jpg`、`windows-tray.jpg`、`windows-tray-menu.jpg`、`gnome-tray-menu.jpg`、`kde-tray-menu.jpg`

**Whisper 日常的入口。** 主窗口处理复杂的事，托盘处理「顺手做一下」。现在的托盘只有菜单（显示、隐藏、发送剪贴板、发送文件、退出），这是全新的界面。

**图标本身是状态**，单色跟随系统：平时是一个环（App 图标的简化，不放字母），传输时环变成进度，有请求待处理时多一个小红点（后两项还没做，见 `decisions.md`「待定」）。深浅切换：macOS 是模板图，系统反色；Windows 读任务栏的深浅，两秒内换成白色或深色那份；Linux 判断不了面板的深浅（GNOME 的顶栏在浅色模式下也可能是深的），用深浅底上都看得见的彩色版。

**左键打开面板，右键保留原生菜单（显示、隐藏、发送剪贴板、发送文件、退出）。Linux 没有面板，只有菜单，见「各平台的托盘」。** 面板宽 340，圆角 24，`panel` 玻璃 + `e3` + 高光，最高为屏幕减 44，超出滚动。内边距上 18、左右 10、下 8（底部有一排小图标，本来就松，顶部要多留一点才匀称），模块间距 8。窗口整个淡入（macOS 的材质画在内容后面，内容单独动会和材质分开），内容同时下移 6、从 0.98 放大，走 `snappy`。模块圆角 `l`，`control` 玻璃，内边距 10。

从上到下，正在发生的事在前，没内容的部分不占位：

1. **时刻**：请求（标题、允许、拒绝）和传输（进度环、文件名、发到哪、取消），每个一块模块。和灵动岛同一份数据。
2. **窗口**：正在流转的窗口，名字、显示于哪台，拿回来或结束。
3. **发送**（没有连着的设备时，这一块换成最近的设备和「连接」）：上面是要发的东西（剪贴板内容、刚截的图或拖进来的文件，单行截断，下面小字「剪贴板」或「发到哪台？」，右边截图或取消），下面一排已连接设备的写实图（高 38）和名字。**点一台就发**，那一格用 `accent` 闪一下。拖着文件悬停时那一格有 2 的 `accent` 外圈。
4. **声音、键鼠**：两列，最小高 54，图标圆 32，名称，下面状态（`关` 或「放到 iMac、Xiaomi 16」）。进行中图标圆是 `accent`。点开就地展开，高度走 `smooth`：
   - 声音：每台已连接设备一行（勾选 22、名字、左 / 全 / 右）。设成单声道的成员三个都不选中，选一个就改掉。接收时写来源，加暂停和断开。
   - 键鼠：屏幕缩略图（高 96，有壁纸和名字，长名字取第一个词，开启时有指针）、键鼠共享开关、「排列」进入完整页面。被控时写来源和停止。
5. **最近的剪贴板**：最近 5 条，**包括当前这条**，有一条就显示，启动时先记下剪贴板里现有的内容。只在内存里，退出就没了。文字或截图小图、来源和时间。**点一下就拷贝，列表不动**：右边的拷贝图标原地变成 `accent` 的勾，0.9 秒后变回去，没有底色，也不换文字。发送模块换成它。别处新拷贝了东西，它才排到最上面。**不放最近传输的文件。**
6. **底部**：「打开 Whisper」文字按钮和设置图标，靠右。只放图标时看不出是回主窗口。

**规则**：

- 点面板外面或按 Esc 关闭，失去焦点也关。发送后不关，方便接着发。请求待处理时不自动关。
- 不复制设置和历史，面板里只放现在就能做完的事。
- 没有配对设备时只显示连接新设备。
- 操作在面板内完成，不跳主窗口，除非要处理复杂的事。

**剪贴板历史是新功能**，现在的 App 没有。默认：只放内存，最多 5 条，退出就清空，不写数据库。本地存储没有加密，密码不能落盘。

- **敏感内容不记录**：macOS 的 `org.nspasteboard.ConcealedType`，Windows 的 `ExcludeClipboardContentFromMonitorProcessing`，Linux 的 `x-kde-passwordManagerHint`。要原生代码读，没验证过。读不到标记的平台，历史默认关闭，等用户决定。
- **只记文字和截图**，不记文件：复制文件时剪贴板里附带的文件名也不记。来自别的设备的同步内容也记，来源写那台设备。
- **拷贝回去算一次普通的复制**，会按现有规则自动同步。`lib/helper/clipboard_write_suppression.dart` 防止这次写入又被记成新条目。

### 各平台的托盘

| | 左键 | 位置 | 拖文件 |

**没有托盘的桌面**：原版 GNOME 没装 AppIndicator 扩展时图标根本不显示，这时「关闭时隐藏到托盘」（默认开）会让窗口再也找不回来。要查 `org.kde.StatusNotifierWatcher` 这个 D-Bus 服务：没有时关闭按钮改成最小化，设置里这一行不可用，写明原因。**现有 App 也有这个问题，没验证过。**

**未验证的技术风险**，开工前先验证：

| 项 | 情况 |
|---|---|
| 面板窗口 | `tray_manager` 只提供图标和菜单。面板要一个无边框小窗口。`desktop_multi_window` 已经用在投屏窗口（`lib/cast_receiver/playback_window.dart`），方向可行，但没有试过当面板用 |
| 面板和主引擎的状态 | 多窗口是独立引擎，协调器单例不能直接共享，要走窗口间通信 |
| 拖到托盘图标 | macOS 菜单栏项可以接收拖放，没有实测。Windows 确定不行，见上 |
| 面板的亚克力 | Windows 用 `DWMWA_SYSTEMBACKDROP_TYPE = 3`。实测主窗口能用，但背后有深色窗口时偏灰，所以面板上面必须再叠 `panel` 的底色。面板窗口本身没有试过 |

现有入口：`lib/page/deviceList.dart:528`（菜单）、`DesktopQuickSendHotKeyController`（`lib/helper/desktop_quick_send_hotkey.dart`，发送剪贴板）。

手机没有托盘，对应的是灵动岛和系统通知。

## 灵动岛

截图：`desktop-island-request.jpg`

纯黑胶囊，浅色深色都一样，白字。

**位置**：永远在**整个窗口**的水平正中，层级最高，盖在设备卡片和弹层的遮罩上面。不左右让。桌面和有侧栏的触控屏距窗口顶 9（触控加状态栏高度），浮在工具栏上；**会盖住标题或工具栏控件时落到工具栏下面**，距窗口顶 58，水平还是正中。展开后如果碰到窗口按钮，往下让到按钮下方 6。手机：**永远在状态栏下方 6**，高 36、宽 176。不进状态栏：系统的时间和图标画在应用上面会透过来，摄像头会挡住一块，那一条的点击也被系统拿走。后台的悬浮窗岛同样。**应用内永远悬浮**，盖在页面上，不把任何东西往下顶。桌面和手机是同一个岛。位置和尺寸变大走 `expressive`，变小和离开走 `snappy`，外形和内容怎么一起变见 `DESIGN.md`「动效」的灵动岛一条。

- **收起**：高 34，圆角 17，内边距左 10 右 13，最宽 320。一个图标、一句话、数值、总数角标（有多件时）。
- **展开**（点一下）：宽 372，圆角 26，内边距 10。每项：32 的图标圆、标题（`note` 半粗）、说明（`tiny`，白 62%）、右边 28 的圆形按钮（取消或停止）。有请求时展开不会因点外面收起。

- **出现**：从缩放 0.6 淡入。

**什么时候显示**：岛说的是**现在看不到的事**。这件事自己的进度就在屏幕上时，岛让位，一个信号不说两遍。

| 级别 | 是什么 | 这件事自己在屏幕上时 | 在别的界面 | 手机在后台 |
|---|---|---|---|---|
| 1. 要回答 | 文件访问、配对、投屏请求，送来的窗口，这台正被别人流转 | **照样显示**，打开直到有答复或超时 | 同左 | 系统岛和通知，带按钮 |
| 2. 出问题 | 局域网断开、传输或拷贝失败 | 失败已经写在卡片上：不显示，看过就算了 | 打开 6 秒，收成小岛，留到恢复或被划走 | 系统通知 |
| 3. 进行中 | 传输、拷贝、声音、键鼠 | **不显示** | 小岛。用户刚发起的拷贝打开一下（3.8 秒）；传输不打开 | 系统岛和通知 |
| 4. 一次性结果 | 已配对、已拷贝 | 不存在这种情况 | 小岛，2.6 秒后消失。完成的传输变勾 | 不显示 |

| 活动 | 主体 | 不算在屏幕上的情况 |
|---|---|---|
| 对话里的传输 | 那张文件卡片 | 卡片滚出列表，切到别的分页或设备，上面压着别的页面 |

| 放声音、收声音 | 声音页 | 手机没有这一页，一直显示 |
| 控制别的电脑、被控制 | 键鼠页 | |

**侧栏那一行不算**：它只有一行小字，换到别的界面还是要有岛。全屏看窗口时只显示第 1、2 级。手机在前台时，请求用页面或弹层，不上岛。

**屏幕顶部的浮岛**（macOS、Windows）：键鼠共享时粘贴别的设备复制的文件，0.3 秒内没到齐，这次粘贴先放下，键鼠照常，同一个岛浮到**有指针的那块屏幕**顶部正中（菜单栏或工作区下方 9），盖在所有应用上面，全屏应用也一样，Whisper 窗口关着也显示。它是自己的窗口，不抢键盘、不把 Whisper 提到前面，窗口只有岛加阴影那么大，屏幕其他地方照常点。

- **来时**：小岛，再打开 3.8 秒。标题是文件名（多个时「3 个文件」），说明「从 小新 粘贴 · 29% · 还剩 12 秒」，× 取消。收起后是进度环、文件名、百分比，点一下再打开。
- **到齐**：粘贴是在资源管理器、访达的文件夹或桌面里按的，不管前台现在是什么，都把文件直接拷进按粘贴时的那个文件夹（重名加序号，不覆盖），变勾，打开写「已放到「桌面」」，2.6 秒后离开。在别的应用里按的：前台还是那个窗口，就替用户再按一次粘贴，变勾、「已粘贴」，2.6 秒后消失；换了窗口不粘贴，打开 6 秒写「已就绪，按 ⌘V 粘贴」（Windows 是 Ctrl+V）。不切回原窗口。
- **没到**：橙色警告「没能粘贴」，6 秒后消失；取消写「已取消」，很快消失。
- **前一个没到齐又粘贴了别的**：前一个不取消，两个都传完、都按上面的规则粘贴，先到的先粘，前一个写进剪贴板后留 2 秒再轮到下一个。打开的卡片一个粘贴一行，窗口跟着变高，最多算 5 行；还一点没收到的写「从 小新 粘贴 · 等前一个传完」，没有百分比。同一份复制粘贴两次只粘最后那次。
- 这些传输不再上应用内的岛，一件事只说一遍。Linux 没有浮岛（没有测试机），文件到了照样粘贴。

**顺序**，收起时显示第一件：请求、送来的窗口、出问题、这台正被流转、拷贝和传输、声音、键鼠。

**这些尺寸都是估算，只用来试布局，不能写进判断。** 由分辨率和对角线按 160 dpi 算出来，用户调「显示大小」后还会变。iPhone 折叠屏苹果没有公布，用的是传闻的参数按 3 倍算的。

| 设备 | 状态 | 宽×高 | 尺寸类 |
|---|---|---|---|
| iPad 11 英寸 | 竖着 / 横着 | 820×1180 / 1180×820 | 常规 / 宽屏 |
| | 分屏（一半） | 405×820 | 紧凑 |
| iPhone 折叠屏（传闻） | 合上 | 474×696 | 紧凑 |
| | 打开 | 904×640 | 常规 |
| 阔折叠（Pura X Max） | 合上 | 487×712 | 紧凑 |
| | 打开 | 1006×711 | 宽屏，刚过线 |
| 小阔折叠（Pura X） | 打开竖着 / 横着 | 533×857 / 857×533 | 紧凑 / 常规，高度不够 |
| 三折叠（Mate XT） | 一屏 / 两屏 / 三屏 | 422×937 / 860×937 / 1337×937 | 紧凑 / 常规 / 宽屏 |

**要留意的三种窗口：**

- **又宽又矮**（合上的阔折叠、打开的小阔折叠）：还是紧凑的页面栈，但比普通手机宽 100 多。气泡上限是 80% 和 30 个字宽里较小的一个，不会铺满。
- **刚过 1000 的宽屏**（打开的阔折叠）：不需要特别处理，设备卡片盖在内容上，所以不提高 1000 这条线。
- **刚过 600 的常规**（半开的 iPhone 折叠屏 640 宽）：侧栏 240，内容 400，和一台手机差不多宽。工具栏里标题最多占三分之一，放不下时灵动岛落到工具栏下面。

**控制页**（触控板 + 左键、滚动、右键）：

| 状态 | 布局 |
|---|---|
| 普通 | 和手机一样，占满内容区 |
| 高度不够 | 按键竖着放在触控板右边，宽 110 |
| 桌面姿态 | 折痕以上：设备图 104、名称、「正在控制」。折痕以下：触控板和按键。侧栏收起，上下两块之间留 36 让开折痕 |
