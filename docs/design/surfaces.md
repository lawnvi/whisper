# 各界面规格

全局规则和 token 在 [`DESIGN.md`](../../DESIGN.md)。这里写每个界面的结构、尺寸、状态和文案。[原型](whisper-ui-language.html)是质感和手感的参照，[截图](reference/)是静态参照。两者不一致时以本文为准，并修正原型。

尺寸单位都是逻辑像素。`触控` 指手机、平板和折叠屏，和窗口多宽无关。

**现有功能清单**是底线：重做时这些操作不能少。原型为了聚焦，有些没有画，以清单为准。

## 窗口外壳（桌面）

截图：`desktop-chat.jpg`、`windows-chat.jpg`、`gnome-chat.jpg`、`kde-chat.jpg`

```
┌────────┬───────────────────────────┬─────────┐
│ 侧栏    │ 工具栏（52）        灵动岛     │ 设备卡片 │
│ 252    │ 内容                       │ 296     │
│ 玻璃    │ 实色                       │ 默认关闭 │
└────────┴───────────────────────────┴─────────┘
```

- 窗口圆角 `m`，`e3`。
- 尺寸类：宽（≥1000）设备卡片并排，内容变窄；常规（600 到 1000）设备卡片浮在内容上，距窗口边 10，圆角 `l`，`e2`；紧凑（<600）见「手机」。
- 工具栏和内容同色，不画线。内容滚动后下方出现 0.5 的 `sep`。内边距左 20、右 12。标题 `head` 半粗，最多占 34% 宽度，超出截断。
- 最小 720×480。现有 App 没有设最小尺寸，用 `windowManager.setMinimumSize`。
- 所有桌面平台都隐藏系统标题栏（现在是 `TitleBarStyle.normal`，`lib/main.dart:136`，要改成 `hidden`），工具栏和内容融为一体。

**窗口按钮**：`WindowButtons`（`flutter.md`），画在窗口最上层，遮罩和弹层都盖不住它，和系统自己的按钮一样。

| | 样子 | 位置 |
|---|---|---|
| macOS | 红绿灯，系统画，直径 12，间距 8，距边 16 | 侧栏左上 |
| Windows | 46×32 的方块，图标 11，悬停 `fill`，按下 `fill2`。关闭悬停 `#C42B1C` 白叉，按下 `#B02A1C` | 贴右上角，距顶 0 |
| GNOME | 直径 24 的圆，底 `fill`，悬停 `fill2`，按下 `ink3`，圆之间隔 8，图标 14。命中区 32 | 圆距顶 14、距边 12，和工具栏同一条中线 |
| KDE | 直径 24，平时没有底，悬停 `fill2`，关闭悬停 `#DA4453` 白叉，圆之间隔 4，命中区 28。最小化是向下箭头，最大化是向上箭头，还原是菱形（Breeze 的习惯） | 同 GNOME |

- 悬停的颜色直接变，不走弹簧，系统按钮就是这样。不进 Tab 顺序，Alt+Space、Alt+F4 这些系统快捷键负责键盘操作。读屏名称：最小化、最大化或还原、关闭。
- **按钮在左**：GTK 的 `gtk-decoration-layout` 决定两边各放什么。Ubuntu 是 `:minimize,maximize,close`，原版 GNOME 是 `appmenu:close`（只有关闭），有人设成 `close,minimize,maximize:`（全在左）。左边的按钮放在侧栏顶部，右边的放在工具栏右上。设置改了要实时跟着变。
- **工具栏留位**：右内边距 = 12 + 按钮总宽（`WindowButtons.widthOf`）。宽屏打开设备卡片时按钮落在卡片上方，这个留位随卡片宽度一起收回，走同一个弹簧。
- **设备卡片和弹层让开**：设备卡片距顶 40（Linux 44）。设置等弹层上下各留出按钮的高度，弹层自己的关闭按钮不被盖住。按钮只在左边时都恢复默认。
- **最大化**：圆角变成 0，图标换成还原。双击工具栏或侧栏顶部的空白也能切换。
- **关闭**：沿用现有逻辑，开着「关闭时隐藏到托盘」就隐藏，否则退出。
- **失去焦点**：云母由系统退成纯色，不用处理。

## 侧栏

截图：`desktop-chat.jpg`、`desktop-offline.jpg`

玻璃 `sidebar`，右边 0.5 的 `sep`。列表内边距 8 / 10。

**顶部**（高 32）：搜索、声音、键鼠三个 28 的图标按钮，靠右。声音和键鼠正在进行时图标是 `accent`，当前打开时底色 `selected`。不放常驻搜索框。Windows 和 Linux 左上角没有红绿灯，写 App 的名字「Whisper」（`note` 中等 `ink2`，左边距 20），上内边距 10，让这一排和工具栏同一条中线。按钮放在左边时不写名字。

**设备列表**：一个列表，不分组。顺序用 `StableDeviceOrder`（`flutter.md`）：

- 打开窗口时排一次：连着的、附近的（配对过和没配对的放一起）、不在附近的。
- **变差不动**：下线的留在原位变灰，它的位置仍然算原来那一档。
- **变好上移**：连上或被发现时移到新档位的最后面，走 `smooth`。新设备同样。不会把上面的行顶下去。
- 不按最新消息跳动。

**设备行**：最小高 46，内边距 7 / 10，行距 2，圆角 `s`。悬停 `fill`。左边是写实设备图，占 34×30 的格子（电脑宽 32，手机高 30），名称 `body` 中等，状态 `note`，都单行截断。固定两行，不加第三行。

**选中底**：一个元素，不是每行各画一个。底色 `sidebar-selected`，投影加细轮廓加高光，像分段控件的滑块。切设备时走 `snappy` 滑到新的行，中途再切会接着滑。进共享页时淡出，回来时直接到位再淡入。

第二行按优先级取第一个成立的：

| 情况 | 文字 | 颜色 |
|---|---|---|
| 正在连接 | 正在连接… | `ink2` |
| 没配对、在附近 | 在附近 · 可以配对 | `ink2` |
| 配对过、在附近、没连接 | 在附近 | `ink2` |
| 离线 | 离线 · 昨天 22:14 | `ink2` |
| 正在传输 | log.txt 59% | `accent`，中等字重（手机上也一样，下同） |
| 它把声音放到这台 | 声音放到这台 | `accent` |
| 它在控制这台 | 正在控制这台 | `accent` |
| 指针在它那里 | 键鼠正在控制它 | `accent` |
| 放着这台的声音 | 放着这台的声音 | `accent` |
| 有流转窗口 | 2 个窗口 | `accent` |
| 其他 | 最新一条消息或文件名 | `ink2` |

选中行上状态的颜色不变。设备图：连着的和没配对的是原本的颜色，配对过、在附近但没连接的略淡（饱和 0.7，不透明 72%），离线的灰度加半透明（50%）。手机同样。

**左下角**：内边距 6 / 8 / 10 / 10，最小高 46。这台的设备图标（18）和名字（`note` 中等，占剩余宽度，超出截断），右边紧挨着 3 个 28 的图标按钮：连接新设备、共享链接、设置。共享链接正在进行时图标是 `accent`，当前打开时底色 `selected`。

**这台面板**（点名字，桌面是弹层）：设备图 96、名字、二维码 148、「另一台设备扫这个二维码就能连上这台」、地址、身份指纹、输入地址…、完成。发现不了时不显示二维码，写「这台不在局域网里，其他设备发现不了它」。局域网断开时左下角图标变 `warn`，灵动岛提示，布局不动。

**右键设备行**（手机在设备页）：断开连接或连接、设备卡片、离线时移除这台设备。

**只有这台时**（还没有配对过）：列表位置写一句「连接第一台设备」和一个按钮，打开连接设备。

现有入口：`lib/page/deviceList.dart`，分组数据来自 `ChatSessionListBuilder`。

## 设备页

截图：`desktop-chat.jpg`、`desktop-files.jpg`、`desktop-apps.jpg`、`desktop-tab-switch.jpg`

工具栏：名称，右边分页胶囊（对话、文件、应用，高 30）和信息按钮（打开时 `accent` 加 `fill` 底）。不写「已连接」。

分页切换用 `LiquidSegmented` 和 `WhisperTabView`（`flutter.md`），规则见 `DESIGN.md`「动效」。默认分页：记住每台设备上次的分页，第一次进对话。

**分页第一次显示时才创建**，之后留着，输入框内容和滚动位置都在。`RemoteFilesPage` 一创建就会向对方请求访问，所以不能提前创建。

**切设备、进共享页、开设置**不是分页切换，没有方向：内容从下方 5、透明，走 `smooth`，侧栏不动。切设备时分页内容重建，草稿沿用现有逻辑（`SendMessageScreen`）。

没连接（文件、应用）：垂直居中，设备图 84、「iMac 没有连接」（`title`）、一句话、连接按钮（`lg` 填充）。连接中按钮写「正在连接…」。

没连接（对话）：能看历史。输入框禁用，占位「连接 iMac 后可以发送」，右边的按钮换成一个「连接」（填充）。

没配对：设备图 84（灰色壁纸）、「2698b 在附近」、「请确认两台设备显示相同的 6 位数字」、数字（等宽 30 半粗）、「数字相同，配对」。

## 对话

截图：`desktop-chat.jpg`、`desktop-composer-shot.jpg`、`phone-chat.jpg`

列表铺满内容区，内边距 8 / 16 / 84（触控 8 / 12 / 92）。

- **气泡**：对方 `bubble` + `ink`；我发的 `accent` + 白字。内边距 7 / 13，圆角 18，`body`，行高 1.45。宽度上限：指针 min(72%, 30 个字宽)，触控 80%。**折行后也收到最长一行**，见 `WhisperBubble`。
- **间距**：同一人连续 2，换人 8。时间 `tiny` 居中，上 14 下 8。
- **文件卡**：宽 min(276, 82%)，内边距 10 / 12，圆角 18，底色 `bubble`，靠对应一侧。白纸图标 30，文件名单行，下面大小和进度，次要字用 `ink2-glass`。传输中多一条进度条和取消，完成写「已送达」。
- **发出的消息**从输入框升起：从下方 26、缩放 0.9、透明，走 `smooth`，变换中心在右下。

**输入框**：`control` 玻璃胶囊 + `e2` + 高光。指针：居中，宽 min(620, 100% − 96)，距底 16，内边距 5。触控：宽 100% − 36，距底 24。从左到右：

1. 输入框，占位「发给 iMac」，名字太长时省略。
2. 发送剪贴板（28 图标按钮）。
3. 截图（只有桌面）。现有规则不变：框选后进剪贴板，粘贴到输入框预览再发。截图和粘贴的预览以 22 的小图 + 名字 + 移除，放在输入框左边。
4. 发送键（28，触控 38）：没内容时是中性底的 `+`，点开菜单选文件、文件夹（手机是文件、照片）；有字或附件时变 `accent` 底的箭头，两个图标旋转 90° 交叉过渡。

**现有功能放在哪**（原型没有画，按这里做）：

| 功能 | 新位置 |
|---|---|
| 消息菜单（右键，手机长按） | 复制、打开、所在文件夹（桌面的文件）、重试（失败时）、选择、删除 |
| 多选 | 进入后工具栏分页换成「已选 3 项」和「取消」，输入框位置换成同样玻璃的操作胶囊：全选、复制、删除 |
| 删除 | 现有确认框，可保留收到的文件 |
| 拖放发送 | 拖进内容区时，内容区内缩一圈 3 的 `accent` 外框（圆角 `m`），中间胶囊「发给 iMac」。放下直接发。对方不在线时写原因 |
| 粘贴预览 | 输入框上方长出一行预览（图片 64 方块，文件带图标），可以横向滚动，每个有移除。胶囊圆角变 21，高度走 `smooth` |
| ⌘⌥V 快速发送 | 现有 `DesktopQuickSendHotKeyController` 和 `lib/widget/desktop_quick_send_dialog.dart`，换成标准弹层，保留「稍后」 |
| 发送失败 | 气泡或文件卡下面 `tiny` `warn`「没有发出去」和小图标，点一下重试。暂停、等待重连的传输在文件卡写状态，给继续 |
| 图片和视频消息 | 现有 `lib/widget/media_message_preview.dart`，无气泡底，最宽 240，圆角 `m`，视频带播放标 |
| 链接 | `accent` 带下划线；在我发的气泡上是白字带下划线 |
| 搜索聊天记录 | 桌面并入 ⌘K，手机在设备页 |
| Android 通知消息 | 普通气泡，第一行是应用和标题 |

现有入口：`lib/page/conversation.dart`（`SendMessageScreen`，已有 `embedded`）、`lib/widget/chat_message_list.dart`、`lib/widget/chat_composer.dart`、`lib/widget/screenshot_controls.dart`。

## 文件

截图：`desktop-files.jpg`、`phone-files.jpg`

像访达，不画线。

- **路径行**（内边距 0 / 20 / 8，`note`）：后退（根目录时变淡）、**位置**（弹出按钮，写当前设备）、子文件夹路径；右边「5 项」、筛选、更多。
- **位置菜单**：这台排第一，然后是已连接的其他设备，每台下面是它的常用位置（收藏）。**这台的文件在这里**，现有 `RemoteFilesPage` 就是一个窗口管所有设备，只是把侧栏收进这个菜单。切到别的设备时侧栏的选中也跟着变。
- **更多菜单**：新建文件夹、列表或图标视图、显示隐藏文件、刷新、传输（打开现有的传输列表，`remoteFilesTransfers`）。
- **列头**（`tiny`，`ink2`）：图标 20、名称（弹性）、大小 84、修改日期 76，内容区宽于 800 时多一列种类 90，间距 10。点列头排序。窗口窄时依次收起种类、大小、日期。手机没有列头，只留大小。
- **行**：高 30（触控 48），外边距 12（触控 8），内边距 14，圆角 `xs`（触控 `s`）。**没有分隔线和隔行底色**。悬停 `fill`。**选中是实心 `accent` 白字**，和访达一样。
- **图标**：文件夹是蓝色实心（`#5AB0F7` 底、`#7CC4FB` 面），文件是白纸（白底、折角 `#E6E6EA`、0.7 描边 `rgba(0,0,0,.34)`）。
- **操作胶囊**：选中文件时从底部升起，距底 18（触控 24），`control` 玻璃，内边距 5。别的设备的文件：拷到这台（填充）、发到…、取消选择。这台的文件：发到…（填充）、共享链接、取消选择。**共享链接只对这台的文件**（`shareLinksSupported`，现有代码也这样）。
- **右键**（手机长按）：打开、拷贝、拷到这台或发到…、共享链接（这台的文件）、重命名、删除、在文件管理器中打开（挂载）。手机：长按弹底部弹层，多选时操作在胶囊里。

| 状态 | 显示 |
|---|---|
| 等待对方允许 | 垂直居中，设备图 84、「请在 iMac 上点允许」 |
| 对方拒绝 | 「iMac 拒绝了」、重试 |
| 空文件夹 | 「这个文件夹是空的」 |
| 读取失败 | 原因、重试 |

切分页时行依次升起，见 `RiseIn`。

**其他现有功能不变**：图标视图，多选，拖放和 ⌘C/⌘V 跨设备拷贝，访问请求（走灵动岛：允许一次、始终允许、拒绝），全部快捷键（`docs/superpowers/specs/2026-10-17-remote-files-design.md`）。原型只画了列表视图。

**覆盖 Finder 外观的要求见 `decisions.md` 待定项 5。**

现有入口：`lib/page/remote_files/`（`RemoteFilesPage`）。它自带 `Scaffold`、侧栏和工具栏，要拆出一个不带外壳的内容组件（比如加 `embedded`，和 `SendMessageScreen` 一样），才能嵌进分页。`FinderColors` 迁移时并入 `WhisperColors`。

## 应用（窗口流转）

截图：`desktop-apps.jpg`、`desktop-viewer.jpg`

内边距 4 / 20 / 30，分区间距 24。分区标题 `note` 半粗。

1. **正在流转**（有才显示）：内缩分组，每行「备忘录 / 运行于 iMac，显示于 Xiaomi 16」，右边「结束」，这台的窗口写「拿回来」。
2. **‹设备› 上的应用**：最近窗口的缩略图（最小宽 160，间距 12，图高 96，圆角 `s`，底 `canvas`，`e1`，悬停 3 的 `accent` 外圈，下方 `tiny` 标题），再下面是应用图标（50，圆角 12，竖向渐变，顶边 0.5 高光；格子最小宽 76）。
3. **送到 ‹设备›**：这台的窗口缩略图。

**动画**：拉过来：窗口从被点的图标放大，先显示模糊快照，第一帧到了变清晰（0.5 秒）。送出去：缩小到 28×20，沿弧线（高度为水平距离的 16%，至少 46）飞向侧栏里那台设备，那一行用 `accent` 30% 闪一下；放下后灵动岛提示「备忘录 已显示在 iMac」。原型里窗口是内嵌示意，真实窗口是原生窗口。

窗口栏：名称、运行于、暂停、送到、关闭，更多里是静音、键盘、文字大小、旋转（现有 `lib/page/window_stream/flow_window_viewer_page.dart` 的功能都保留）。暂停只停画面，静音单独控制，关闭把应用送回来源设备的后台。

**工具栏多一个「更多」**（分页是应用时）：画质（`windowStreamQuality`）。对方是手机时，「‹设备› 上的应用」上方有搜索框（`windowStreamSearchApps`）。

**通过 adb 发现的手机**（`lib/window_stream/adb/`）作为一台「在附近」的设备出现在设备列表，点进去是应用分页。不支持时不显示。

**取消**：流转文档里的设备色光晕和背景渐变，固定时长的 `SpringCurve`，顶部设备架（和侧栏重复）。

**保留**：运行于和显示于的模型，拉过来和送出去的动画方向，⌘K 搜索，窗口是原生窗口。

现有入口：`lib/page/window_stream/`（`FlowSpacePage`，已有 `focusPeerId`），协调器 `lib/window_stream/window_stream_coordinator.dart`。

## 设备卡片

截图：`desktop-device-card.jpg`、`regular-device-card.jpg`、`dark-device-card.jpg`

## 声音

截图：`desktop-audio.jpg`、`desktop-audio-idle.jpg`、`desktop-audio-sink.jpg`、`dark-audio.jpg`

**事实**（`lib/audio/audio_group_coordinator.dart`）：

- 只能由来源发起。协议只有来源到接收端的邀请，接收端能暂停、重新加入和断开。
- 一台设备同时只有一种角色。接收端只能加入一个来源。
- 每个成员有声道（立体声、单声道、左、右）和状态，独立失败。
- 没有按成员调音量的协议。增益只影响接收端自己。

**页面**（电脑），侧栏顶部进入，背景 `canvas`，内容列最宽 620，居中，内边距 0 / 20 / 28，分块间距 18。

1. **页头**：这台的设备图 96、声波（5 根，宽 3、间距 3、高 18，放着时动，停着时是灰点）、标题 `title`、一句 `body` `ink2`。
2. **勾选列表**（内缩分组，分隔线缩进 60）：只列连着的和在附近的设备，不在附近的不列。每行高 60：设备图 36（占 38 宽）、文字、声道、右边圆形勾选 22。**同步情况就写在这一行**：放着的时候，第一行是名称（`body`，太长就截断）加同步质量（`note` `ink2`，有问题时 `warn`，不截断），第二行是具体数字「网络 2ms · 抖动 1ms · 缓冲 80ms · 晚包 0」（`note` `ink2`，等宽数字）。还在估算时数字写「—」，这样不跳。没放的时候只有名称，下面按状态写「未连接」或「已停止」。**点勾选就开始放**，不用再点开始。在附近没连接的变淡，写「未连接」，不能选。
3. **声道就在行内**：左、立体声、右、单声道，分段控件，高 36（按钮 30，内边距 3），勾选后才出现。不另外展开，每行一样高。
4. **总开关**（有成员才显示）：共享这台的声音，关闭后成员留着。**不另外做同步详情**。数字那一行不带同步质量，因为名称旁边已经写了；现有 `audioGroupSyncEvidenceCompact` 带质量前缀且没有单位，要新加一个键。

**声道默认值**：第一台立体声。第二台加入时，如果用户没动过声道，自动分成左右。剩一台时回到立体声。第三台起立体声。

| 状态 | 页头标题 | 页头副标题 | 成员状态 |
|---|---|---|---|
| 没有成员 | 放到其他设备 | 选几台设备，它们会一起响。 | |
| 正在建立 | 正在放到 2 台设备 | 正在估算同步 | 名称旁边写正在估算同步，下面的数字是「—」 |
| 放着 | 正在放到 2 台设备 | 同步良好 / 同步一般 / 同步波动（取最差的） | 同一组词，写在名称旁边，「同步一般」和「同步波动」用 `warn`，下面一行是数字 |
| 总开关关闭 | 放到其他设备 | 选几台设备，它们会一起响。 | 已停止 |
| 某台失败 | 同上 | 同上 | 这一行写原因，其他不受影响 |

**接收端的增益行**：内缩分组，最宽 320，居中，比上面的页头和下面的按钮不宽太多。标签和滑块紧挨着（间距 12），滑块占剩下的宽度，右边写「1.0x」。不铺满 620 的内容列，不要标签在最左、滑块在最右（截图 `desktop-audio-sink.jpg`）。设置里的滑块行不变，那里是右对齐的长列表。

**接收端**（别的设备把声音放到这台）：页头是来源的设备图和声波，「正在播放 iMac 的声音」，副标题「要换来源，先断开」或「已暂停」；增益滑块（1 到 3）；暂停 / 继续、断开。

**成员状态**（`AudioGroupSinkState`）：

| 状态 | 行内文字 |
|---|---|
| `offered`、`accepted`、`connecting` | 正在连接… |
| `active`，还没有同步数据 | 正在估算同步（`audioGroupSyncCalibrating`） |
| `active`，有数据 | 同步良好、同步一般、同步波动。判断逻辑沿用 `_audioGroupSyncQualityLabel`（`lib/page/deviceList.dart`）：有晚包、误差超 30ms 或抖动超 20ms 是波动，误差超 12ms 或抖动超 8ms 是一般 |
| `lagging` | 同步波动 |
| `failed` | 没有放出来，选中看原因。`lastError` 是 `AudioFailureReason` 的名字，用 `audioFailureReasonFor` 和现有的 `_audioFailureDetail` 转成文字 |
| `stopped` | 已断开。对方暂停或断开都是这个状态，可能回来（`sinkJoinRequest`），留在列表里，保持勾选 |

**不支持组播放的旧设备**（`supportsAudioGroupSinkFor` 为假）也列出来，只是它不能和别的设备一起放：没有声道控件，下面写「只能单独放」。勾选它时取消其他成员，走 `AudioShareCoordinator.startSharingToConnectedPeer`；已经单独放给它时勾选别的设备，先停止它。

**没有权限**（`AudioFailureReason.permission`，macOS 上是屏幕与系统录音）：页头副标题写「需要允许屏幕与系统录音」，下面一个「去开启」按钮，打开系统设置。此时列表可以勾选，但不开始。

**当前平台不能采集**：不显示这一页的入口。

**窄窗口**：内容列窄于 520 时，声道分段收成弹出按钮（写当前声道，点开带勾的菜单），名字保住空间。

**接收端的细节**，来自 `AudioIslandSource`：

| 情况 | 能做什么 |
|---|---|
| 组播放，放着 | 暂停、断开 |
| 组播放，已暂停，来源支持重新加入（`audioGroupRejoinV1`） | 继续、断开 |
| 组播放，已暂停，来源不支持 | 只能断开，不显示继续 |
| 继续中 | 副标题「正在恢复…」，按钮禁用 |
| 旧版一对一来源 | 只能断开，没有暂停 |

**手机**只有接收端，没有这一页，控制在灵动岛和那台设备的设备页。

**增益要改代码才能实时生效**：现在组播放只在开始时读一次（`lib/audio/audio_group_coordinator.dart:1384`）。接收端的滑块拖动时要立刻起作用，这是新工作，给协调器加一个设置增益的方法。

现有入口：`lib/page/deviceList.dart:2414` 和 `lib/page/conversation.dart:1973` 各有一个设置面板，合并成这一页。不支持组播放的旧设备走 `AudioShareCoordinator` 的一对一，界面不区分。

## 键鼠

截图：`desktop-input.jpg`、`desktop-input-on.jpg`、`desktop-input-drag.jpg`、`desktop-input-controlled.jpg`、`dark-input.jpg`

**事实**（`lib/remote_input/`）：

- 只能由控制端发起。正在被控制的设备不能再发起。
- 每台设备可以有多块屏幕，布局保存，自动吸附，屏幕之间形成路由。
- 状态：等待确认、已就绪、控制中、失败（`RemoteInputWorkspaceTargetStatus`）。连接后的失败每个目标独立。
- **但未互信或对方不能被控制时，`startControllerWorkspace` 和 `updateControllerWorkspaceRoutes` 整体失败**。所以开启前先用 `RemoteInputWorkspaceTargetRequest` 的 `isMutuallyTrusted`、`remoteCanInject` 过滤，把这些设备标成「没有连上」，其他的照常开始。重试就是带上它再调一次 `updateControllerWorkspaceRoutes`。
- 指针在别的设备上时，这台的界面点不到，所以**没有「回到这台」按钮**，只有快捷键和推回来。
- 退出快捷键 `Ctrl+Alt+Esc`（macOS `Control+Option+Esc`），对方断开时指针自动回来。
- 手机不能当被控端。

**页面**（电脑），侧栏顶部进入，像系统设置的显示器排列。工具栏右边是总开关。内边距 0 / 20 / 14，分块间距 14。

1. **画布**：占满剩余高度（最少 240），圆角 `m`，底 `fill`，内阴影 `inset 0 1px 3px rgba(0,0,0,.06)`。内容按比例缩放居中，四周留 28，每逻辑像素最多 0.13。屏幕增减时缩放走 `smooth`。
2. **屏幕块**：按真实比例。圆角 `xs`，壁纸渐变，顶部 7%（至少 4）的白色半透明菜单栏，整体压一层渐暗，阴影 `0 2px 8px rgba(0,0,0,.2)`。多块屏幕分开画，间隙 2。名字在中间（`note` 半粗，白字），下面一行状态只写：离线、等待确认、没有连上、正在控制。屏幕太矮（<44）时不显示状态。
3. **候选**（画布下方，有才显示）：胶囊，高 34，白底 `e1`，32×22 的迷你屏幕加名字。**拖到画布或点一下就加入**，拖出画布就移出。离线的禁用。
4. **底部**（最小高 28，`note`）：
   - 没选中、没开启：「拖动屏幕来排列。指针从相接的边过去。」
   - 没选中、开启：「按 ⌃⌥Esc 收回键鼠」，这是安全出口，不能省。
   - 选中屏幕：名字、分辨率、「在右边」，失败时写原因和「重试」，右边「移出」。

**交互**：

- 拖动时屏幕抬起（投影 `0 14px 22px rgba(0,0,0,.34)`），跟手（`follow`），显示吸附预览（`accent` 22% 底、1.5 描边）。放下用 `snappy` 贴到预览位置。键盘：方向键移动 100 逻辑像素，Shift 400，Enter 选中。
- **屏幕不会悬空**。只能贴在指针走得到的屏幕旁边（从这台开始，经过相接的在线屏幕能到达）。挪走一块后，接在它旁边的屏幕自动贴回去。所以正常操作里不会出现「边缘重叠」和「没贴边」的错误。复用 `RemoteInputWorkspaceSnapper` 和 `RemoteInputWorkspaceMagnetizer`。
- 离线的屏幕留在原位，变灰变淡，写「离线」。
- 选中的屏幕有外圈：外扩 3，2.5 的 `accent`。
- 总开关明确开启，不像声音那样点了就开始，因为它会接管指针。开启后画布里有真实的箭头指针（15×21），显示它现在在哪台。
- 一台失败不影响其他：`没有连上`，选中它看原因（比如「它还没有信任这台」）和重试。

**被控端**：「iMac 正在控制这台」、设备图 96、「要控制别的电脑，先停止。」、停止。判断用 `RemoteInputCoordinator` 的 `state.role == RemoteInputRuntimeRole.sink`，停止用 `stopSharing`。（`RemoteInputWorkspaceRole.controlled` 没有被赋值过，不要用。）

| 异常 | 显示 |
|---|---|
| 没有可控制的电脑 | 画布上只有这台，底部写 `remoteInputWorkspaceNoTargets`，总开关禁用 |
| 这台没有权限（macOS 辅助功能，`lib/widget/macos_permission_setting.dart`） | 底部写原因和「去开启」，打开总开关不生效 |
| 这台不支持（`supportsNativeRemoteInput` 为假） | 侧栏顶部没有键鼠入口 |
| 对方版本不支持（`remoteInputWorkspaceUnsupported`） | 候选里禁用，写「不支持」 |
| 对方没有信任这台（`remoteInputPeerMustTrustThisDevice`） | 屏幕写「没有连上」，选中看原因 |
| 冲突（`remoteInputWorkspaceConflict`） | 布局自动贴回后不应出现；如果对方上报的屏幕变了，自动重排一次 |

现有入口：`lib/remote_input/remote_input_workspace_screen.dart`（三栏，2548 行，替换它），数据 `RemoteInputWorkspaceCoordinator` 和 `RemoteInputWorkspaceSnapshot`。

## 共享链接

截图：`desktop-links.jpg`、`desktop-link-detail.jpg`、`phone-links.jpg`

**不依赖任何设备，也不需要先连接。** 对方不用装 Whisper。桌面左下角进入，手机在设置里。

**现有功能清单**（`lib/page/remote_files/files_shares.dart`、`lib/share_links/`），全部保留：

- 创建：路由、简短路由、密码。入口有两个：这里的新建（用系统文件选取器，可以选多个文件或文件夹）、「文件」位置切到这台后选中文件的共享链接。
- 每条：名称、路由、状态、访问次数、下载次数、最近访问。文件不见时要提示。
- 操作：拷贝、二维码、开启或关闭、删除（要确认，说明不影响本机文件）。
- 文件服务：本机地址、端口、总开关、失败重试。只在有链接开着时运行。多个网络时可以切换链接地址。

**页面**：背景 `canvas`，内容列最宽 620。工具栏右边新建（手机是 `+`）。

- **列表**：一个白色分组，**不画线**，行高 60，内边距 8 / 14，间距 12。每行：文件或文件夹图标 28（关着时透明度 0.45，名字变 `ink2`）、名称（有密码时加 11 的小锁）、统计、开关。桌面悬停时出现「更多」（拷贝链接、二维码和详情、删除链接…）。
- **统计行**：`12 次访问 · 5 次下载 · 今天 17:20`；关着写「已关闭」；服务关着写「文件服务已关闭」；文件不见写「有些文件不在原来的位置了」，前面 12 的 `warn` 小图标，文字仍是 `ink2`。
- **文件服务**（分开一组）：标题，下面地址或「没有开启的链接，服务没有运行」或「链接都打不开」，右边总开关。
- **底部小字**：对方不用装 Whisper，在同一局域网用浏览器打开就能下载。走的是普通 HTTP，密码只防止别人随意打开。
- **没有链接**：图标 40、「还没有链接」、一句话、「选择文件」。

**详情**（点一行，弹层，手机是底部弹层）：名称、二维码、地址框（等宽）、分组（开启、地址、密码、访问、下载）、删除链接（无底 `bad`）、拷贝链接、完成。创建成功后直接进这里。

**新建**（弹层）：「共享「文件名」」、路由（占位是随机路由）、简短路由开关、密码（可不填）、取消、创建链接。路由重复时输入框报错。

**删除确认**：「删除「文件名」？」「这个地址会打不开。本机的文件不受影响。」取消、删除（`bad` 填充）。

## 托盘

截图：`desktop-tray-hold.jpg`、`desktop-tray-clips.jpg`、`desktop-tray-copied.jpg`、`dark-tray.jpg`、`windows-tray.jpg`、`windows-tray-menu.jpg`、`gnome-tray-menu.jpg`、`kde-tray-menu.jpg`

**Whisper 日常的入口。** 主窗口处理复杂的事，托盘处理「顺手做一下」。现在的托盘只有菜单（显示、隐藏、发送剪贴板、发送文件、退出），这是全新的界面。

**图标本身是状态**，单色跟随系统：平时是一个环（App 图标的简化），传输时环变成进度，有请求待处理时多一个小红点。

**左键打开面板，右键保留原生菜单（显示、隐藏、发送剪贴板、发送文件、退出）。Linux 没有面板，只有菜单，见「各平台的托盘」。** 面板宽 340，圆角 24，`panel` 玻璃 + `e3` + 高光，最高为屏幕减 44，超出滚动。内边距 10，模块间距 8。从图标长出来：从缩放 0.9、上移 10，走 `smooth`，变换中心在图标下方。模块圆角 `l`，`control` 玻璃，内边距 10。

从上到下，没内容的部分不占位：

1. **发送**（没有连着的设备时，这一块换成最近的设备和「连接」）：上面是要发的东西（剪贴板内容、刚截的图或拖进来的文件，单行截断，下面小字「剪贴板」或「发到哪台？」，右边截图或取消），下面一排已连接设备的写实图（高 38）和名字。**点一台就发**，那一格用 `accent` 闪一下。拖着文件悬停时那一格有 2 的 `accent` 外圈。
2. **时刻**：请求（标题、说明、这次允许、始终允许、拒绝）和传输（进度环、文件名、发到哪、取消），每个一块模块。和灵动岛同一份数据。
3. **声音、键鼠**：两列，最小高 54，图标圆 32，名称，下面状态（`关` 或「放到 iMac、Xiaomi 16」）。进行中图标圆是 `accent`。点开就地展开，高度走 `smooth`：
   - 声音：每台已连接设备一行（勾选 22、名字、左 / 全 / 右）。设成单声道的成员三个都不选中，选一个就改掉。接收时写来源，加暂停和断开。
   - 键鼠：屏幕缩略图（高 96，有壁纸和名字，长名字取第一个词，开启时有指针）、键鼠共享开关、「排列」进入完整页面。被控时写来源和停止。
4. **窗口**：正在流转的窗口，名字、显示于哪台，拿回来或结束。
5. **最近的剪贴板**：最近 4 条（不含当前这条），文字或截图小图、来源和时间。**点一下就拷贝**，右边图标变成勾（0.9 秒），然后它成为当前内容，排到发送模块里。**不放最近传输的文件。**
6. **底部**：打开主窗口、设置，靠右。

**规则**：

- 点面板外面或按 Esc 关闭，失去焦点也关。发送后不关，方便接着发。请求待处理时不自动关。
- 不复制设置和历史，面板里只放现在就能做完的事。
- 没有配对设备时只显示连接新设备。
- 操作在面板内完成，不跳主窗口，除非要处理复杂的事。

**剪贴板历史是新功能**，现在的 App 没有。默认：只放内存，最多 5 条，退出就清空，不写数据库。本地存储没有加密，密码不能落盘。

- **敏感内容不记录**：macOS 的 `org.nspasteboard.ConcealedType`，Windows 的 `ExcludeClipboardContentFromMonitorProcessing`，Linux 的 `x-kde-passwordManagerHint`。要原生代码读，没验证过。读不到标记的平台，历史默认关闭，等用户决定。
- **只记文字和截图**。来自别的设备的同步内容也记，来源写那台设备。
- **拷贝回去算一次普通的复制**，会按现有规则自动同步。`lib/helper/clipboard_write_suppression.dart` 防止这次写入又被记成新条目。

### 各平台的托盘

| 项 | 情况 |

**这些尺寸都是估算，只用来试布局，不能写进判断。** 由分辨率和对角线按 160 dpi 算出来，用户调「显示大小」后还会变。iPhone 折叠屏苹果没有公布，用的是传闻的参数按 3 倍算的。

**要留意的三种窗口：**

- **又宽又矮**（合上的阔折叠、打开的小阔折叠）：还是紧凑的页面栈，但比普通手机宽 100 多。气泡上限是 80% 和 30 个字宽里较小的一个，不会铺满。
- **刚过 1000 的宽屏**（打开的阔折叠）：打开设备卡片后内容只剩 376，仍然够用，所以不提高 1000 这条线。
- **刚过 600 的常规**（半开的 iPhone 折叠屏 640 宽）：侧栏 240，内容 400，和一台手机差不多宽。工具栏里标题最多占三分之一，放不下时灵动岛落到工具栏下面。
