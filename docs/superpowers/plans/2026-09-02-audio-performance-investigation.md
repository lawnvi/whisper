# 声音共享性能专项

## 状态

- 延后到 UI 调整完成后单独处理。
- 当前 UI 工作不得修改声音采集、编码、缓冲、同步、声道配置数据或传输协议。

## 已知基线

- macOS Debug 构建在声音共享进行中采样约为 17–21% CPU、844 MB 物理占用，峰值约 1.2 GB。
- 同一 Debug 构建重启后空闲采样为约 0% CPU、403 MB 物理占用，峰值约 649 MB。
- 采样热点包含 `MacSystemAudioCapture.copyFloat32`、Opus 编码、Dart PCM 分包分配以及 Flutter 图形缓冲。
- 这组数据不是空闲基线，不能直接代表发布构建的常驻占用。

## 后续范围

- 分别采集 Profile/Release 的空闲、单设备共享和多设备共享基线。
- 检查 PCM 跨平台复制、格式转换、分包队列和 Opus 编码开销。
- 保持现有声道、时钟同步、抖动缓冲和协议行为不变，并以现有音频测试作为回归基线。
- 每项优化独立提交，记录前后 CPU、内存、丢包、延迟和连续播放结果，便于单独回退。
