# 手机控制器：免长按体感、大触控板与横屏键盘

日期：2026-10-06。分支：`codex/mobile-air-mouse-spike`。

## 交互改动

- 体感区改为轻点开启、再次轻点暂停。开启后松开手指仍可转腕移动；开启前 80ms 抑制运动。暂停、切换页面/模式、旋转、后台与断连继续清理按钮和重复按键状态。
- 设备名称和连接状态合并到顶部栏，底部导航压缩到 64dp。触控板占满内容宽度，移除该模式的独立滚动条，保留左右键和拖拽操作。在 360×640 的组件测试中，触控板为 328dp 宽、高度超过 320dp。
- 单指轻点左击，双指轻点右击，双指移动滚动。双指轻点要求第二指在 150ms 内加入、整体在 300ms 内结束、移动不超过 6dp；最后一指抬起时发送一组右键按下/抬起。滚动后、取消、长按、迟到的第二指或第三指均不会误发右击；已按住鼠标按钮时不额外发送轻点点击。
- 进入虚拟键盘时，Android 临时切到横屏；返回鼠标、退出控制页和后台时恢复应用原有竖屏。键盘使用独立紧凑顶部栏与 5 行主键盘，功能键、导航和其余符号放在第二页。保留修饰组合与长按重复，640×360 时主键盘完整显示，极小窗口/大字号仍可滚动。
- 沿用 Whisper 的 Material 3 / WhisperPalette 配色、圆角、字体和深浅主题；新增文案覆盖中、英、西三种语言。

## 范围与兼容性

改动限于手机控制页、手机输入控制器、纯 Dart 触控板手势及对应本地化/测试。没有修改连接协议、认证、能力协商、桌面工作区、文件/剪贴板/音频通道或 macOS 注入。电脑可继续使用现有协议 11 接收端，本轮无需更新。

未修改依赖、锁文件、全局方向策略、Android 清单或签名资产。

## 真机验证状态

新版安装成功后，手机在准备验证期间再次锁屏，随后 ADB 设备列表为空。因此本轮尚未完成设备实际横屏、返回竖屏和双指右击到 Mac 的联机核对；上面的通过结果是自动测试与 Flutter 渲染结果，不代表这些真机项目已经通过。重新连接并进入控制后，可继续在独立 Cocoa 测试窗口核对，不需要重新安装。

真机握持的主观手感、受控静置漂移与高帧率端到端延迟仍需人工验收；自动手势测试不能替代这些指标。此前真机报告中的 20 次拖拽属于上一轮验证，不计为本轮重测。
