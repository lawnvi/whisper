# 手机控制页：竖屏键盘与统一操作栏

日期：2026-10-07。本轮替代此前独立文字页、底部导航和键盘自动横屏设计。

## 交互

- 顶部依次为设备选择、单个鼠标/键盘切换按钮、开始/停止、设置。切换和开始/停止均只显示图标，分别使用主题蓝色、绿色开始、红色停止；保留本地化 tooltip 和读屏名称。切换按钮显示目标页面图标；主体淡出淡入，顶部位置保持固定，不申请屏幕旋转。
- 设备卡片说明精简为“切换后需重新开始控制”，列表底部额外留白 32dp。设备和设置卡片使用 300ms 缓出上滑、220ms 平滑收起，仍遵循系统减少动画设置。动画样式作为弹层工具的可选参数传入，其他页面保持原有样式。
- 鼠标移动区域与底部按钮连为一个面板。左右键等宽，中央滚动区宽 64dp、高至少 88dp；体感模式按住并转腕，触控板模式上下滑动。保留双指右键、双指滚动和按住左键拖拽。移除面板下方的提示文字，将空间留给操作区。
- 直接键盘使用竖屏 QWERTY 26 键，第二排缩进，第三排带 Shift 和退格。底排为 123/ABC、逗号、空格、句号和回车。修饰键、Esc/Tab/方向键常驻；Fn 页提供 F1–F12、导航、Caps Lock 和 Delete。
- 数字和两页符号可直接点按。符号显式构造对应物理键及临时 Shift，发送后释放全部修饰键。其结果仍遵循电脑当前键盘布局和输入法；文字框用于 Unicode 短文本。
- 文字框与直接键盘同页，发送按钮位于输入卡片右下角；空草稿按单行高度展示，输入多行时扩展。聚焦文字框后暂停直接按键并打开手机输入法；返回直接按键或切换鼠标会保留草稿。发送时锁定其他输入，收到匹配回复才清空；超时保留草稿、不自动重发。
- 普通竖屏完整展示键盘；大字号和较短窗口允许纵向滚动。字母键使用手机键盘的窄列，键高至少 52dp，不宣称每个字母键都是 48×48dp。
