# 2026-11-13 提权专项审计

接着 [安全审计与加固](2026-11-13-security-audit.md) 做的第二轮，重点是提权：同一台机器上权限更低的一方（别的用户、同一用户下没被授权的程序、手机上的普通 App）能不能借 Whisper 拿到更高的权限；已配对的设备能不能拿到超出授权的能力。安卓、Windows 各一路只读审计，macOS 和 Linux 我自己查，最后一路查文件浏览客户端对主机回复的处理、原生接收端和键鼠包。每条结论先对着代码核实再修。

全部改动跑过 `flutter analyze`、尺寸检查和完整的 `flutter test`。**没有在真机上验证**（安卓代理在 Android 15 模拟器上实跑过），下面每条注明验证到哪一步。

## 查过并排除的

- macOS 挂载的回环 NFS：导出路径带随机部分、文件句柄带 8 字节密钥、只认第一次 MNT，别的用户和沙盒 App 拿不到句柄。
- GNOME 辅助扩展：校验调用方是本用户、不在沙盒里、可执行文件在白名单内。Linux 上没有 uinput 或 udev 规则。
- Windows 服务管道：DACL 只给会话用户，核对会话号，拒绝远程客户端；客户端核对管道属主是 SYSTEM；请求按固定长度解析，只收键盘和鼠标，是否允许提权由服务每次读 HKLM。
- 安卓代理：握手只收 uid 0/2000 且要 token；手机端 AppLink 用 HMAC 双向证明；状态文件 0600；Provider 先查调用方 uid；导出组件只有主界面和这个 Provider。
- 文件浏览客户端复制到本机：名字经传输引擎校验，文件夹清单拒收符号链接，落位用本地名字。
- 原生接收端抽查（Windows H.264 解码与转换、Linux 解码与声音输出、macOS H.264 切分）：缓冲按行距和行数核对，没找到越界。

## 修了还剩的风险

- 安卓：关掉自动启动后，Whisper 的「写入安全设置」权限和本机配对密钥都还在，Whisper 进程一旦被攻破仍能自己打开无线调试拿 shell。撤销要先连上本机调试，没做。
- Windows：服务代理带着完整的 SYSTEM 特权；管道 SDDL 的写权限包含建实例位（实例数为 1 挡住了）；切换用户时管道名可被别的用户抢先占住（只造成锁屏输入不可用）；「在文件夹中显示」把带逗号的路径交给 explorer 解析。
- 解码炸弹：超大尺寸的图标或 SPS 让接收端按声明的尺寸分配（只有已配对设备能发）。
- 超过 20 万项的文件夹现在列不出来；两页之间主机的缓存过期、文件夹又变小时，这次列表会失败，重新加载即可。
- Windows Cloud Files 的读取只接住挂载自己的错误，别的异常要等系统请求超时。

## 等用户决定

1. Windows 每次升级、在设置里装卸服务或开关 UAC 控制，都以管理员身份运行 `%LOCALAPPDATA%\Programs\Whisper` 里的 `whisper.exe`。这个目录同一用户可写：换掉 exe，或放一个 `winmm.dll` 之类的系统库（静态导入、不在 KnownDLLs 里），用户照常点「是」后就是攻击者的代码以管理员身份运行，还会被复制成 SYSTEM 服务。要修得改升级流程（例如由 Program Files 里那份执行，并校验新文件的签名），或者改成按机器安装。
2. 「浏览我的文件」开放的是整个主目录，含隐藏文件：对方能读 `~/.ssh`、`~/.android/adbkey`（凡是信任过这台电脑的安卓手机，只要无线调试可达就能拿 shell）。允许修改时还能写 `~/.zshrc`、`~/Library/LaunchAgents`、Windows「启动」文件夹，下次登录就执行。
3. 收到的文件点一下就打开：Windows 上 `.exe`、`.bat`、`.lnk`、`.url` 等直接运行，没有 SmartScreen 提示（没有 MOTW）。
4. 已配对设备在手机虚拟屏上能打开「设置」，给自己配无线调试，拿到常驻 adb shell，取消信任也收不回；窗口流转能启动本机任意应用（包括 PowerShell、终端），键盘也不过滤 Win 键。
5. 收到的文件夹或挂载的对端目录里的 `.url`、`.library-ms` 等，在资源管理器里一浏览就会向对端发起 SMB 认证，交出 NetNTLMv2 哈希。
