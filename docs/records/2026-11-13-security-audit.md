## 修了还剩的风险

- 更新签名的私钥在 GitHub Secrets 里，GitHub 账号被盗仍能签。已发出去的旧版本只认哈希。
- 中途放弃的纯配对码握手限速是全局的：局域网里有人可以让首次配对（不含扫码和已配对设备）一次暂停 60 秒。用多个地址发有效 proof 仍能占名额，每个都会弹出可见的配对框。
- 网页传输的未确认访客没有按 socket 计字节（要手写升级，没做）；已确认的访客仍能发一条大消息。
- 观看端按原尺寸解码对端图片，PNG 炸弹的解码峰值没处理（只有已配对设备能发）。

## 等用户决定（改了会改变现有用法）

1. 已配对设备随时能控制本机键鼠，本机没有"允许被控制"的开关；窗口共享默认开。
2. 只开"浏览我的文件"就可以写，只读是黑名单，和使用指南不一致。
3. 收到的文件不打隔离标记（macOS quarantine / Windows MOTW）。
4. macOS 的身份种子明文在 NSUserDefaults；改回钥匙串需要稳定签名。
5. Windows 锁屏服务从用户可写的安装目录复制 CRT DLL。
6. 对端自报的名字可在会话中途改成另一台的名字，出现在授权提示里；窗口目录会把其他观看者的名字告诉来浏览的设备。
7. 电视投屏确认框 5 秒后自动允许。
8. 安卓签名密钥在公开仓库里（用户说密码较复杂，暂不轮换）。
