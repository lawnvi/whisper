# iOS 与 iPad 验证记录

2026-10-09 使用 iPad（第六代）与 iPadOS 17.7.11 验证；工具链为 Xcode 27.0、Flutter 3.41.7，最低支持版本为 iOS 15。

## 构建与安装

在 Xcode 完成组件安装，登录自己的普通 Apple 账号；通过 USB 连接设备，开启开发者模式并信任电脑和自己的开发签名。

```bash
flutter pub get
./script/run_ios.sh
```

脚本构建 release 应用，保留安装并启动，设备可以脱离调试器打开应用；它从 Xcode 的实际构建设置读取产物路径，避免切换构建模式后误装旧副本。多台设备连接时，第一个参数传入 `flutter devices` 显示的设备 ID。

免费 Personal Team 测试配置有效期为 7 天，到期重新运行脚本，详见 [Apple 账号说明](https://developer.apple.com/help/account/basics/about-your-developer-account)。签名账号和证书由本机 Xcode 管理；可通过 `FLUTTER_XCODE_DEVELOPMENT_TEAM` 指定 Team，仓库不保存个人签名信息。

脚本支持 `WHISPER_FLUTTER_BIN`、`WHISPER_IOS_DEVICE_ID`；同一工作目录的 iOS 构建和运行须顺序执行，避免共享配置与产物相互覆盖。首次出现的本地网络和通知权限需在设备确认。

## 适配范围

- 使用 scene 生命周期注册插件，首帧完成后请求权限，忽略页面关闭后的发现回调。
- 作为移动扬声器，支持有界播放队列、后台音频、系统媒体控制和系统打断处理。
- 作为手动键鼠控制端，提供触摸、键盘和运动控制；尺寸切换时释放按住的输入，编辑时暂停运动控制。
- iPad 支持四方向与多任务；宽度达到 840 逻辑像素时显示双栏，缩窄后保留会话与草稿，iPhone 保留竖屏。
- 文件分享使用当前 scene 并设置 iPad 弹出锚点；自动剪贴板监控遵循用户开关，更新安装后迁移历史文件的容器路径。
- 消息宽度按对话区计算，文件卡片移动端最多 360、桌面最多 300 逻辑像素；长文件名最多两行，工具栏随按钮数量和搜索展开自适应。
- 设置页关闭实色背景上的模糊，提前读取数据并在滑入结束后展示，关闭时清理等待。

iOS 当前支持音频接收和手动键鼠控制；系统音频采集、全局键鼠注入及其他应用通知读取仍遵循原有平台能力约束。
